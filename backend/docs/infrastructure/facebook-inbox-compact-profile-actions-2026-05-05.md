# Facebook Inbox Compact Profile Actions

## Summary

تم ضغط واجهة `/facebook-inbox` في منطقتين تشغيليتين مهمتين:

- شريط إجراءات الرسائل لم يعد يظهر بمجرد المرور على نص الرسالة، وأصبح يظهر فقط عند الضغط على زر ثلاث نقاط صغير بجانب الرسالة.
- لوحة بيانات العميل الجانبية أصبحت أقصر وأكثر كثافة، مع عرض الهوية والإحصائيات والتحكم الأساسي في مساحة أصغر.
- نسخة الديسكتوب من عمود بيانات العميل لم تعد تكرر صورة واسم العميل بجانب هيدر الشات، وأصبح يمكن إخفاء/إظهار العمود من زر بيانات العميل.

## Frontend Changes

- `frontend/src/components/facebook-inbox/MessageBubble/MessageBubble.tsx`
  - إضافة زر `MoreHorizontal` لفتح إجراءات الرسالة عند الضغط.
  - إغلاق القائمة عند الضغط خارجها.
  - إخفاء قائمة التفاعل عند إغلاق قائمة الإجراءات.
  - تصغير زر الإجراءات وأزرار القائمة، وتثبيت القائمة للداخل من حافة الرسالة لمنع قصها عند طرف الشات.
  - تثبيت أبعاد أزرار القائمة وإضافة ألوان واضحة للأيقونات حتى لا تظهر كدوائر فارغة.
  - استبدال أنواع `any` القديمة في بيانات الرسالة بأنواع محددة.

- `frontend/src/components/facebook-inbox/CustomerProfile/CustomerProfile.tsx`
  - تقليل صورة العميل إلى `48px`.
  - تحويل الهيدر من تخطيط عمودي كبير إلى صف مضغوط.
  - دمج اسم العميل، سنة العميل، واسم الصفحة في نفس كتلة الهوية.
  - عرض الطلبات والقيمة كمؤشرات صغيرة.
  - ضغط الحالة والتعيين داخل شبكة قصيرة.
  - دمج أزرار الصوت، الإشعارات، إنشاء الطلب، والحظر في شريط واحد بارتفاع `32px`.
  - تقليل هوامش التابات ومساحة المحتوى الداخلي.
  - إضافة وضع `compactHeader` لنسخة العمود المثبتة على الديسكتوب، بحيث يظهر الملخص الرقمي والتحكم فقط بدون تكرار صورة واسم العميل.
  - اختصار أزرار إنشاء الطلب والحظر إلى نصوص قصيرة، وتحويلها إلى أيقونات فقط في الوضع المضغوط مع إبقاء `title` و`aria-label`.

- `frontend/src/pages/facebook-inbox/FacebookInbox.tsx`
  - إضافة حالة محفوظة في `localStorage` لإظهار/إخفاء عمود بيانات العميل على الديسكتوب.
  - تحويل زر بيانات العميل في هيدر الشات إلى مفتاح إخفاء/إظهار للعمود في الشاشات الواسعة.
  - منع فتح Overlay بيانات العميل على الديسكتوب عند إخفاء العمود، مع إبقاء سلوك Overlay للموبايل كما هو.
