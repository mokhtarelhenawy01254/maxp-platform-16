# 🤖 Automation Workflows (n8n / Make)

## Workflow 1: IG DM Auto-Outreach
```
Trigger: New follower (filtered by bio keywords)
  → Wait 24h
  → Send DM: Template A
  → Wait 3 days, no reply → Send Template B
  → Wait 3 days, no reply → Send Template C
  → Tag as "Engaged / Cold"
  → Add to CRM
```

## Workflow 2: Lead Magnet → Nurture → Demo
```
Trigger: Download "10 Orders Checklist"
  → Add to CRM as "Lead - D2C"
  → Send Email 1 (Welcome + Quick win)
  → Wait 2 days → Email 2 (Case study)
  → Wait 3 days → Email 3 (Demo offer)
  → If clicked demo → Book in Calendly
  → If not → Email 4 (Last chance)
  → Wait 5 days → Add to retargeting FB audience
```

## Workflow 3: Multi-Channel Inbound Router
```
Trigger: New message (any channel: WA, IG, FB, Email, Web form)
  → Classify by source + vertical
  → Route to correct sales rep (round-robin)
  → Auto-reply within 5 min
  → Create deal in CRM
  → Schedule follow-up
```

## Workflow 4: Demo → Trial → Customer
```
Trigger: Demo booked
  → Send prep email (24h before)
  → Run demo
  → Send "Free Trial" link
  → Wait 1 day → Check trial activity
  → If active → Sales call
  → If inactive → Re-engage sequence
  → If converted → Onboarding workflow
```

## Workflow 5: Customer → Cross-sell
```
Trigger: Customer reaches usage milestone (e.g., 100 orders)
  → Auto-send: "Ready for [next module]?"
  → Tag for relevant campaign
  → Sales follow-up
```

## Workflow 6: Cold Outbound (B2B / Wholesale / Clinic)
```
Trigger: List from Apollo / Sales Navigator
  → Personalized email (variable: company, role, pain)
  → Wait 3 days → LinkedIn connect
  → Wait 3 days → LinkedIn message
  → Wait 5 days → Follow-up email
  → Wait 7 days → Phone call
  → Tag and route
```

## Workflow 7: Reseller / Affiliate Pipeline
```
Trigger: Application submitted
  → Auto-approval check
  → Welcome email + onboarding video
  → Add to private Telegram/Discord
  → Send first commission opportunity
  → Track conversions
  → Monthly performance email
```

## Workflow 8: Hotel Direct Booking Recovery
```
Trigger: New hotel customer signup
  → Day 0: Welcome + setup checklist
  → Day 3: "Setup your first property"
  → Day 7: "Import your OTA listings"
  → Day 14: "Launch direct booking"
  → Day 30: "Case study - 30% direct bookings"
  → Day 60: "Cross-sell: Guest messaging"

# 💰 Budget Recommendation (حسب الفريق)

## Solo Founder (Budget: $1,000-3,000/month)
- **Focus:** 1-2 verticals max
- **Channels:** Organic (FB Groups, LinkedIn, IG organic) + 1 paid channel
- **Tools:** Apollo ($50/mo), ManyChat ($15/mo), Calendly (free), n8n Cloud ($20/mo), HubSpot Free
- **Outbound:** 50 DMs/day, 30 emails/day
- **Target:** 5-10 new customers/month

## Small Team (2-5 people, $5,000-15,000/month)
- **Focus:** 3-5 verticals
- **Channels:** All organic + 2-3 paid channels
- **Tools:** Apollo + Instantly + LinkedIn Sales Nav + ManyChat + n8n + Pipedrive
- **Outbound:** 200 DMs/day, 100 emails/day
- **Field reps:** 1-2 (for clinics/hotels)
- **Target:** 30-50 new customers/month

## Growth Team (5-20 people, $20,000+/month)
- **Focus:** 10+ verticals
- **Channels:** Full paid mix + content + partnerships + events
- **Tools:** Full stack + Sales team
- **Outbound:** 500+/day
- **Field:** 5-10 reps
- **Target:** 100-200 new customers/month

# 🔁 Cross-Channel Sequence (مثال D2C)

```
Day 0: IG comment (under their post)
Day 1: IG DM (template A)
Day 3: IG DM (template B) [if no reply]
Day 5: Email (lead magnet offer)
Day 7: FB friend request
Day 10: FB message
Day 14: Retargeting ad
Day 21: Email (case study)
Day 30: Last touch → mark as cold

If reply at any point → human takes over
```

# 🧪 Testing Framework

لكل Vertical، اعمل:
- 3 Hook variations
- 3 Channel variations
- 3 Offer variations (free trial / demo / case study)
- Budget: $100 per variation
- Run for 7 days
- Scale winning combo

# 📋 Daily/Weekly Checklist

## Daily (1-2 hours)
- [ ] 50 IG DMs (ManyChat + manual)
- [ ] 30 cold emails (Instantly)
- [ ] 10 LinkedIn messages
- [ ] 5 cold calls (Clinics/Hotels)
- [ ] Respond to all inbound (5 min SLA)

## Weekly (5-10 hours)
- [ ] Review conversion data
- [ ] Update lead lists
- [ ] A/B test new hooks
- [ ] Content: 3 posts (IG/LinkedIn)
- [ ] Community engagement (FB Groups)
- [ ] Partner outreach (5-10)
- [ ] Refine automation workflows

## Monthly
- [ ] Quarterly review of all channels
- [ ] Customer interviews (5-10)
- [ ] Update personas (new insights)
- [ ] Launch new lead magnet
- [ ] Recalculate unit economics
- [ ] New vertical exploration
