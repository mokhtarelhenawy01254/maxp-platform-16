# محرر واجهة المتجر — حزمة تصميم وبروتوتايب (جلسة Hermes · أكتوبر 2026)

مجلد مرجعي **لا يمس كود التطبيق** ولا التوجيه — أُعدّ خلال جلسة عمل على محرر الواجهة
`/settings/storefront/editor`، ويجمع ثلاث حزم:

## 1) `designs/` — أربعة اتجاهات تصميم (2026)
لوحة تفاعلية (`index-gallery.html` — افتحها في المتصفح، فيها تابات + عرض الكل) لأربع اتجاهات
مستوحاة من: **شوبيفاي 2026** (Canvas First — التنقل في الشريط العلوي والمعاينة في المنتصف)،
**ووردبريس 2026** (Blocks & Styles — شجرة كتل + كتاب أنماط)،
**Wix Studio 2026** (Pro Studio — أربع لوحات + نقاط توقف + Responsive AI)،
و**اتجاه AI-first 2026** (مساعد مدمج + بطاقات مراجعة التغييرات).
اللقطات المُرندرة في `design-previews/`.

## 2) `editor-prototype/` — بروتوتايب محرر "Pro Studio" مُختبر
`StorefrontEditor.tsx` — صفحة محرر كاملة (React + Tailwind، RTL):
لوحة عناصر + طبقات، كانفس حيّ بمكونات المتجر الفعلية، فاحص سياقي،
**سحب وإفلات HTML5** (إضافة أقسام + إعادة ترتيب بمؤشر إفلات)، تراجع/إعادة،
حفظ تلقائي + نشر، مبدّل أجهزة (سطح مكتب/تابلت/جوال)، زوم، ووضع معاينة.

- **نتيجة الفحص الحي: 10/10 اختبارات ناجحة** (تحديد، تعديل مباشر، إضافة قسم،
  سحب وإفلات، سلسلة تراجع/إعادة، تبديل جهاز، زوم، معاينة، فشل حفظ آمن بدون خادم، تسجيل المسار).
- `editor-harness.html` + `src/harness/editor-harness.tsx` = مدخل اختبار محلي بدون تسجيل دخول
  (الطريقة: Vite multi-page entry + MemoryRouter).
- `screenshots/` — لقطات من النسخة الشغالة فعليًا.
- **ملاحظة:** هذا بروتوتايب مرجعي؛ التنفيذ الإنتاجي الحيّ موجود في
  `apps/frontend/src/storefront/studio/` (Storefront Studio).

## 3) `elementor/` — كتالوج أدوات Elementor الكامل (2026)
ملف عربي شامل (`elementor-tools-catalog.html`) يجمع كل أدوات إلمنتور كما في أكتوبر 2026:
محرر V4 الجديد (عناصر Atomic، Variables، Classes، Components، Interactions)،
الودجات المجانية، ودجات البرو (85)، Theme Builder، التسويق (Popup/Form/Dynamic)،
ووكومرس، الذكاء الاصطناعي (**Angie** + **MCP** + Ally)، خدمات Elementor One،
والرودماب — مُجمَّع من المصادر الرسمية (elementor.com: widgets/features/pro/ai/ecommerce/roadmap/help
+ developers.elementor.com + سجل الإصدارات 4.3.x + مراجع خارجية متخصصة).
