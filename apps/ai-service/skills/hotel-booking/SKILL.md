# مهارة حجز الفندق

## متى تستخدم
عندما يطلب الضيف:
- التحقق من توفر الغرف: "عايز أتأكد منAvailability في تاريخ كذا"
- الحجز: "عايز أحجز" / "حجزت قبل كده" / "ألغي الحجز"
- "هل في غرف متاحة" / "بدي أحجز" / "show available rooms" / "I want to book" / "cancel my booking"
- التنقل بين الخطوات: معلومات → توفر → حجز → استعلام → إلغاء

## الأدوات

### hotel_check_availability
| البند | الوصف |
|-------|-------|
| **المدخلات** | check_in (تاريخ الوصول), check_out (تاريخ المغادرة), property_id (اختياري). إذا كانت التواريخ فارغة، الأداة تطلبها. |
| **المخرجات** | أنواع الغرف المتاحة: roomTypeId, name, capacity, available, effectivePrice, basePrice, amenities |
| **الاستخدام** | قبل كل حجز — تأكد من التوفر في التواريخ المطلوبة |
| **خطأ** | empty data → "لا توجد غرف متاحة في هذه التواريخ" |
| **needs_dates** | إذا كانت needs_dates=true في الاستجابة، اسأل الضيف عن تاريخ الوصول والمغادرة |

### hotel_reserve
| البند | الوصف |
|-------|-------|
| **المدخلات** | customer_name, customer_phone, check_in, check_out, property_id (مأخوذ من hotel_info), rooms (array of objects: [{'roomTypeId': '...', 'roomId': '...', 'nightlyRate': 500}]), adults, children |
| **المخرجات** | reservation: id, status, totalAmount, room assignments, customer details |
| **الاستخدام** | بعد موافقة الضيف على نوع الغرفة والسعر والتواريخ — استخدم property_id من hotel_info و rooms كـ array of objects |
| **تحذير** | property_id مطلوب (استخدم hotel_info أولاً). rooms يجب أن يكون array of objects وليس string |
| **خطأ** | error → "حدث خطأ في إنشاء الحجز. تأكد من صحة البيانات وحاول مرة أخرى." |
| **موافقة بشرية** | غير مطلوبة (requiresHumanApproval: false) |

### hotel_my_reservations
| البند | الوصف |
|-------|-------|
| **المدخلات** | phone (رقم جوال الضيف) |
| **المخرجات** | حجوزات الضيف: id, status, checkIn, checkOut, totalAmount, rooms |
| **الاستخدام** | عندما يسأل الضيف عن حجوزاته — استخدم رقم الجوال للتصفية |
| **خطأ** | empty → "لا توجد حجوزات مسجلة بهذا الرقم" |

### hotel_cancel_reservation
| البند | الوصف |
|-------|-------|
| **المدخلات** | reservation_id (معرف الحجز), company_id (auto-injected) |
| **المخرجات** | تأكيد الإلغاء + reservation object محدث |
| **الاستخدام** | بعد تأكيد هوية الضيف (اسأل عن رقم الجوال واستخدم hotel_my_reservations أولاً) |
| **ممنوع** | لا تلغي حجز CHECKED_IN → وجّه للدعم البشري |
| **حالة** | فقط PENDING أو CONFIRMED يمكن إلغاؤها |

## تدفق القرار
```
طلب الضيف
   │
   ├─ "معلومات" ─────────→ hotel_info ───→ عرض + سؤال عن الحجز
   │
   ├─ "توفر/حجز جديد" ──→ hotel_check_availability
   │                           │
   │                    ┌──────┴──────┐
   │                    │             │
   │                 متاح؟         غير متاح؟
   │                    │             │
   │               اعرض + سعر    "للأسف لا توجد..."
   │                    │          اقترح تواريخ أخرى
   │              ┌─────┘
   │              │
   │         يوافق الضيف؟
   │              │
   │         hotel_reserve
   │              │
   │         اعرض تفاصيل الحجز
   │
   ├─ "استعلام عن حجوزاتي" ──→ hotel_my_reservations ──→ عرض القائمة
   │
   └─ "إلغاء حجز" ──→ hotel_my_reservations (تأكيد الهوية)
                          │
                     هل رقم الجوال يطابق؟
                          │
                     hotel_cancel_reservation
                          │
                     تأكيد الإلغاء
```

## صيغة العرض

**بعد التحقق من التوفر:**
```
🟢 الغرف المتاحة من 20 يوليو إلى 22 يوليو:

• 🛏️ غرفة مفردة — 500 ج.م/ليلة (1 متاحة)
• 🛌 غرفة مزدوجة — 750 ج.م/ليلة (2 متاحة)
• 👑 جناح — 1,200 ج.م/ليلة (1 متاح)

📊 الإجمالي التقريبي: 1,000 - 2,400 ج.م لليلتين
```

**بعد الحجز:**
```
✅ تم تأكيد الحجز بنجاح!

🧑 الضيف: أحمد محمود
📅 الوصول: 20 يوليو 2026
📅 المغادرة: 22 يوليو 2026
🛏️ غرفة مفردة — 500 ج.م × 2 ليالٍ
💰 الإجمالي: 1,000 ج.م
📋 رقم الحجز: #cmrxxx
🟡 الحالة: قيد الانتظار (PENDING)
```

## خطوات التنفيذ (Progressive Disclosure)

| الخطوة | الإجراء | الأداة |
|--------|---------|--------|
| 1 | اسأل عن تاريخ الوصول والمغادرة | — |
| 2 | تحقق من التوفر | hotel_check_availability |
| 3 | اعرض الخيارات مع الأسعار | — |
| 4 | اجمع بيانات الضيف (الاسم، الجوال) | — |
| 5 | أنشئ الحجز (موافقة بشرية مطلوبة) | hotel_reserve |
| 6 | اعرض تفاصيل الحجز النهائية | — |

**لا تتقدم للخطوة التالية دون إكمال السابقة.** الضيف يحدد الوتيرة.

## ممنوعات
| ممنوع | الصح |
|-------|------|
| تأكيد الحجز دون موافقة صريحة | انتظر "تم" / "أكد" / "احجز" من الضيف |
| اختلاع أسعار | استخدم فقط ما ترجعه hotel_check_availability |
| خلط حجوزات ضيوف مختلفين | كل ضيف له رقم جوال فريد |
| إلغاء حجز CHECKED_IN | "الحجز قيد الإقامة — حول للدعم البشري" |
| مشاركة معلومات حجز مع ضيف آخر | كل جلسة خاصة بصاحبها |
| تجاهل خطأ الأداة | اعتذر بلطف وأقترح المحاولة لاحقاً |
| التخمين عند عدم توفر response | "لم تصلني معلومات كافية — كرر الطلب من فضلك" |

## الانتقال بين المهارات
- **hotel-info → hotel-booking:** بعد عرض معلومات الفندق، انتقل للحجز إذا طلب الضيف
- **hotel-booking → hotel-info:** ارجع للمعلومات إذا سأل الضيف عن أنواع الغرف أو الأسعار
- **hotel-booking → Handoff:** إذا طلب الضيف شيئاً خارج نطاق الفندق، استخدم agent_handoff_to
