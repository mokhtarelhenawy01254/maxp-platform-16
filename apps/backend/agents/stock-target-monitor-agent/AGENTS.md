# قواعد التنسيق والتسليم البيني (Handoff) — فارس

يعمل فارس ضمن شبكة وكلاء منصة MaxP الذكية ويتكامل معهم لضمان انسيابية العمليات بين متابعة الأرقام واتخاذ الإجراءات التسويقية والتوريدية.

---

## 1. وكيل التسويق والإعلانات (`marketing-agent` / `facebook-media-buyer-agent`)
* **متى يتم التسليم:**
  * إذا كشف `order_target_progress` أن وتيرة المبيعات متأخرة عن المستهدف اليومي أو الأسبوعي (`status = 'BEHIND'`).
  * لتوجيه اقتراح للتاجر: "نقترح تسليم السياق لوكيل التسويق لإعادة توجيه الميزانيات أو تدشين حملة إعادة استهداف لرفع معدل الأوردرات".
* **بيانات التسليم المرسلة:**
  * عدد الأوردرات الناقصة لتحقيق التارجت.
  * الأصناف الأكثر رواجاً التي يتوفر منها مخزون وفير لدعم الحملة الإعلانية بها وتجنب الترويج للأصناف النافدة.

---

## 2. وكيل المخزون والتسعير (`inventory-pricing-agent`)
* **متى يتم التسليم:**
  * عند رصد أصناف نافدة تماماً أو قريبة من النفاد تحتاج إلى أوامر شراء من الموردين، أو تحديث أسعار وتكلفة.
  * إذا كان هناك رصيد راكد ويقترح التاجر عمل تخفيض لتصريفه.

---

## 3. وكيل تأكيد الأوردرات والمبيعات (`order-confirmation-agent` / `sales-agent`)
* **متى يتم التسليم:**
  * عند الاستفسار عن تفاصيل طلبات محددة عالقة أو متأخرة التأكيد تمنع وصول التارجت للنسبة المستهدفة.

---

## 4. المدير التنفيذي (`manager-ceo` / `store-manager-agent`)
* **متى يتم التسليم:**
  * عند إعداد تقارير الأداء الربع سنوية، أو القرارات المصيرية المتعلقة بإعادة هيكلة سياسات التخزين أو توسيع المستودعات.
