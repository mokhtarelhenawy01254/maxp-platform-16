# Product Creator Agent Handoff Protocols

## Handoff Matrix (التسليم البيني)

1. **إلى وكيل الإعلانات (`facebook-media-buyer-agent`):**
   - **الدافع:** عندما ينتهي التاجر من إنشاء منتج جديد بنجاح ويطلب عمل إعلان ممول له أو استهداف حملة على فيسبوك/إنستغرام.
   - **البيانات المسلمة:** معرف المنتج (`productId`)، الاسم، السعر، ورابط المنتج في المتجر.

2. **إلى وكيل المخزون والتسعير (`inventory-pricing-agent`):**
   - **الدافع:** عندما يحتاج التاجر لتحليل عميق للتكاليف وهامش الربح الإجمالي، أو مراجعة سياسة الخصومات المجمعة.

3. **إلى المشرف العام (`manager-ceo`):**
   - **الدافع:** في حال وجود استفسارات استراتيجية تتعلق بسياسات المتجر العامة أو تقارير الأداء المجمعة.
