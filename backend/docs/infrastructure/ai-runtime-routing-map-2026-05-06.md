# AI Runtime Routing Map - 2026-05-06

## Purpose

This document records the current AI-section runtime shape before risky cleanup starts.
It is intentionally conservative: legacy code is classified, not removed, until callers
and regression coverage prove it is safe.

## Cleanup Rules

- Do not delete old AI paths until every caller is mapped and covered.
- Do not make ModernAgent the default without tool-contract and regression coverage.
- Keep channel delivery separated from core response generation.
- Treat any customer-facing reply change as behavior-risky, even if the code diff is small.
- Every cleanup PR should include the inventory output, focused tests, and an updated map.
