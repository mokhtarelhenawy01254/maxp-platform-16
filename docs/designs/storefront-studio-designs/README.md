# محرر المتجر البصري — تصميم السحب والإفلات (Storefront Studio · Drag & Drop)

مجلد مرجعي يجمع: **لوحة التصاميم الأربعة** التي أُعدّت لاختيار شكل محرر المتجر
(`/settings/storefront/editor`) + لقطات + ملخص التنفيذ.

## المحتويات
- `storefront-editor-4-designs.html` — اللوحة التفاعلية (افتحيها في المتصفح مباشرة).
  فيها 5 تابات: **الحالي (مرجع)** + **A / B / C / D**.
- `shots/` — لقطات لكل تاب + لقطتان من الموقع الحي بعد النشر:
  - `live-editor-with-drag-grips.png` — المحرر الحي وفي قائمة «الهيكل» مقابض السحب ⠿.
  - `designs-board-view.png` — شكل اللوحة أثناء المراجعة.

## التصميم المختار والمنفَّذ ✅
**A · استوديو كلاسيكي** — نفس التخطيط الحالي بالحرف (هيكل يمين / كانفس وسط / خصائص شمال)
+ إضافة **السحب والإفلات**: مقبض ⠿ لكل قسم في الهيكل وعلى شريط القسم في الكانفس،
خط أزرق يوضّح مكان النزول، وبحث في الأقسام.

- B و C و D: أفكار بديلة **لم تُنفّذ** (مرجع للمقارنة فقط).
- «Click & Drop» = اسم الفكرة (سحب وإفلات) وليست تابًا مستقلًا.

## إزاي تجربيها على الموقع
1. افتحي `/settings/storefront/editor` (اعملي Hard Refresh مرة واحدة: Ctrl+Shift+R).
2. من «الهيكل» → امسكي مقبض ⠿ لأي قسم واسحبيه لفوق/تحت (الخط الأزرق = مكان النزول).
3. أو من الكانفس → شريط أدوات القسم فيه مقبض سحب كذلك.
4. زر التراجع ↺ من الشريط العلوي يرجع أي ترتيب.
