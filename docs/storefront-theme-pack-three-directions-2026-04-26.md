# Storefront Theme Pack: Three New Fashion Directions

This pack adds three intentionally different Arabic fashion themes instead of small cosmetic remixes.

## Themes

### `hayah-modest-eg` / Hayah

- Core idea: modestwear discovery built around coverage, layering, and outfit compatibility.
- Signature first fold: `promo-strip` -> `hero-banner(modest-cascade)` -> `offer-bento(bundle-matrix)`.
- Key shopping logic: start from the base piece, then add only the layer that closes the look.

### `rihla-resort-eg` / Rihla Resort

- Core idea: travel and resortwear sold through destination, weather, and packing logic.
- Signature first fold: `promo-strip` -> `hero-banner(runway-grid)` -> `featured-collections(travel-postcards)`.
- Key shopping logic: every collection answers what deserves space in the bag.

### `layali-edit-eg` / Layali Edit

- Core idea: evening and occasionwear routed by invitation type, formality, and urgency.
- Signature first fold: `promo-strip` -> `hero-banner(fashion-billboard)` -> `offer-bento(campaign-stack)`.
- Key shopping logic: begin with the occasion before browsing the rack.

## New Variants

- `HeroBanner.modest-cascade`: layer-first modest-fashion hero with stacked outfit cards.
- `FeaturedCollections.travel-postcards`: postcard-style travel routing for resort and packing scenarios.
- `ShopCommandBar.occasion-planner`: guided occasion toolbar for event-led shopping.

## Why They Differ

- Hayah reduces noise and frames the decision as coverage plus layering.
- Rihla makes the bag and destination the primary organizing system.
- Layali focuses on invitation context and fast occasion-based decision making.
