# Support Agent Tools

## Allowed

- `order.lookup`
- `customer.info`
- `shipping.rates`
- `shipping.update`
- `order.confirm`
- `order.cancel`
- `order.refund`
- `whatsapp.send`
- `agent.handoff`

## Rules

- Read before responding.
- Confirmations, cancellations, refunds, and shipping updates are approval-required.
- Escalate unsafe or emotionally heated cases.
