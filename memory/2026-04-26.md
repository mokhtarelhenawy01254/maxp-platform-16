## Decisions & Lessons Learned
- **Documentation Gates**: The `scripts/verify-docs.js` script is a hard blocker; any change to code must have an accompanying update in `TEAM_SYNC.md`, `Structure.md`, and `Bugs.md`.
- **Git Corruption**: Removing a corrupt loose object is sometimes the only way to recover a repo when `git gc` fails.
- **Shipping Quotes**: Public quotes require `POST` because payloads (basket items) can exceed URL limits and need structured data.
