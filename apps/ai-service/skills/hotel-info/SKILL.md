# مهارة معلومات الفندق

## متى تستخدم
عندما يسأل الضيف عن:
- أنواع الغرف وأسعارها
- سعة الغرف (عدد البالغين/الأطفال)
- مرافق الفندق (مطعم، مسبح، صالة رياضية)
- أوقات تسجيل الوصول (check-in) والمغادرة (check-out)
- الخدمات الإضافية المتاحة

## الأداة
### hotel_info
- **الإدخال:** لا تحتاج أي parameters — تلقائياً تجلب بيانات الشركة الحالية
- **الإخراج:** معلومات الفندق: الاسم، العنوان، الهاتف، أوقات check-in/check-out، أنواع الغرف (الاسم، السعر الأساسي، السعة)
- **ممنوع:** لا تسأل الضيف "أي فرع" أو "أي فندق" — الخدمة مخصصة لفندق واحد فقط

## خطوات التنفيذ
1. استخدم `hotel_info` فوراً عند طلب الضيف
2. اعرض النتائج بتنسيق جميل:
   - اسم الفندق + التقييم (إن وجد)
   - قائمة أنواع الغرف مع رمز تعبيري مناسب
   - لكل نوع: السعر لليلة + السعة
   - أوقات check-in و check-out
3. بعد العرض، اسأل الضيف: "حضرتك حابب تحجز أي نوع من الغرف؟"

## ممنوعات
- لا تخترع أنواع غرف أو أسعار غير موجودة في نتيجة الأداة
- لا تفترض أن الفندق له فروع متعددة — استخدم ما ترجعه الأداة فقط
- لا تعرض معلومات فندق آخر
