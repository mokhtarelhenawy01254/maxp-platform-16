## ✅ اللي شغال صح (متوقفوش)

- **صفر تمرير أفقي:** scrollWidth = 360 = عرض الشاشة بالظبط
- **الأداء:** TTFB 187ms — FCP 752ms — DOM Load 1284ms — **CLS = 0**
- **صفر أخطاء JavaScript** في الكونسول (تحذير واحد فقط)
- **RTL سليم 100%:** dir=rtl وصفر عناصر LTR فيها نص عربي
- **شريطا الثقة والتكاملات:** ماركي مقصوص صح (trust-bar / integration-strip بـ overflow:hidden) — مش عيوب
- **تابات الأقسام:** قابلة للسكرول أفقيًا فعلًا (756px محتوى في 336px)
- لا توجد صور مكسورة (العنصر "المكسور" الوحيد هو pixel tracker noscript — طبيعي)

## 🔴 حرج — يُصلح فورًا

### 1. تباين قراءة شبه معدوم (ratio أقل من 2:1)
نصوص حمراء على خلفية حمراء شفافة — WCAG AA يتطلب 4.5:1:
| النص | التباين | اللون الحالي |
|---|---|---|
| بادج "BUSINESS OS — منصة تشغيل متكاملة" | **1.89** | rgb(217,102,102) على rgba(184,26,26,0.1) |
| "20 أداة في اشتراك واحد" | **1.89** | نفس التوليفة |
| "جولة في المنصة" | **1.89** | نفس التوليفة |
| "Source: WhatsApp • Status: Hot" (موك أب) | **1.36** | rgb(113,113,122) على rgba(184,26,26,0.1) |

**الإصلاح:**
```css
/* بدل النص الأحمر الفاتح */
.badge-red { color: rgb(153, 27, 27); }            /* ratio ≈ 7.0 */
/* أو غمّق الخلفية وحافظ على هوية العلامة */
.badge-red { color: #fecaca; background: rgba(184, 26, 26, 0.85); }
```

### 2. هدف لمس "دخول" = 32×21px
أقل من الحد الأدنى 24×24px (WCAG 2.2 Target Size) — المفضل 44×44.
```css
.header-login { min-width: 44px; min-height: 44px; display: inline-flex; align-items: center; justify-content: center; }
```

### 3. نصوص 10–11px في أقسام كاملة
- وصف المميزات (فقرات p): **11px**
- أسماء التكاملات (WooCommerce, POS, Google...): **11px**
- ليبلات الموك أب الداخلي (Recent Lead, Sales Pulse...): **10px**
- عناوين h3 (المبيعات والتواصل، التشغيل والمخزون...): **13px**

11px عربي على موبايل = إجهاد فوري. الحد الأدنى للكابشن 12px، ولأوصاف 13–14px.
```css
.feature-desc { font-size: 13px; line-height: 1.7; }   /* بدل 11px */
.integration-logo span { font-size: 12px; }             /* بدل 11px */
.premium-section h3 { font-size: 16px; }                /* بدل 13px */
```

## 🟠 متوسط

### 4. صفحة طولها 14,387px بلا هيدر لاصق
~20 شاشة سكرول والمستخدم يضيع — الهيدر position:relative ويختفي بعد أول شاشة، ولا يوجد زر عودة للأعلى.
```css
header { position: sticky; top: 0; z-index: 50; backdrop-filter: blur(8px); background: rgba(255,255,255,.85); }
```
أو على الأقل CTA عائم سفلي + زر ↑ يظهر بعد 2 شاشات.

### 5. أزرار CTA منتفخة 96px ارتفاع
"ابدأ مجاناً" (146×96) و"كلم مستشار" (166×96) في قسم الختام — تبدو منفوخة على موبايل.
```css
.final-cta { min-height: 52px; padding-block: 14px; }   /* بدل 96px */
```

### 6. سلايدر حاسبة الفورسات غير قابل للاستخدام
`input[type=range]` بمقاس 123×16px وبدون aria-label — إصبعك مش هيلمحك، وقارئ الشاشة أعمى تجاهه.
```css
input[type="range"] { min-height: 44px; width: 100%; accent-color: #2563eb; }
```
```html
<input type="range" aria-label="عدد المستخدمين">
```

### 7. عناصر قابلة للنقر بلا دور (role) — 12+ عنصر
تابات الأقسام والـ FAQ والنايفيجيشن كلها `div` بـ onclick — الكيبورد وقارئ الشاشة مش شايفينها.
```html
<!-- بدل div onclick -->
<button type="button" class="module-tab">المبيعات و CRM</button>
<!-- أو كحد أدنى -->
<div role="button" tabindex="0" aria-expanded="false">سؤال شائع؟</div>
```

### 8. زر "استعرض الأدوات" تباينه 3.27 فقط
أبيض على تركواز rgb(20,158,160) — نص 14px مش "كبير" فالمطلوب 4.5:1.
```css
.btn-teal { background: rgb(13, 118, 120); }   /* ratio ≈ 5.1 */
```

## 🟡 بسيط

9. **H1 = 28px** صغير نسبيًا لهيرو موبايل (الموصى به 32–34px)
10. **نص ملتصق** في أكبر عنوان (48px): "10 أنظمة منفصلة؟وفّر" — ناقص مسافة بعد علامة الاستفهام
11. **شريط تابات بلا مؤشر سكرول:** 6 تابات في 336px من غير fade أو scroll-snap يوحي بوجود المزيد
```css
.module-tabs { scroll-snap-type: x mandatory; mask-image: linear-gradient(to left, transparent, black 24px); }
.module-tab { scroll-snap-align: start; }
```
