# Employee Reporting Prototype

This prototype is a static HTML preview for the proposed employee reporting experience before product implementation begins.

## File

- `F:\max_p_new\max_p_new\artifacts\employee-reporting-prototype.html`

## What It Demonstrates

- Arabic RTL interface for daily or weekly reporting
- Employee-facing follow-up form focused on:
  - what was completed
  - blockers
  - next target
- Manager-facing panel showing:
  - submission status
  - blocker concentration
  - target progress
- A separate band clarifying which data can be pulled automatically from the system

## Intent

The prototype is intentionally positioned as a form-driven reporting tool with analytics, not a generic spreadsheet clone. It is meant to validate the interaction and visual direction first.

## How To Review

Open the HTML file directly in a browser. No dev server is required.
