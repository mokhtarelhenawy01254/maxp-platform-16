## 🎯 منهجية الخطة

> **القاعدة الذهبية: القناة أولاً → القناة الفرعية → العميل → الرسالة → التحويل**

```
┌─────────────────────────────────────────────────┐
│  1. القناة (Channel)                            │
│     "فين هنلاقي الناس أصلاً؟"                   │
│     (Instagram, TikTok, GitHub, etc.)            │
├─────────────────────────────────────────────────┤
│  2. القناة الفرعية (Sub-channel)                 │
│     "أنهي جزء بالتحديد من القناة؟"              │
│     (Fashion hashtag, Reels, GitHub trending)    │
├─────────────────────────────────────────────────┤
│  3. العميل (Persona)                            │
│     "مين الشخص اللي هناك؟"                      │
│     (سارة، كريم، فاطمة...)                       │
├─────────────────────────────────────────────────┤
│  4. الرسالة (Hook)                              │
│     "إيش نقوله بالظبط؟"                         │
│     (Script مخصص للـ persona + channel)          │
├─────────────────────────────────────────────────┤
│  5. التحويل (Conversion)                        │
│     "إزاي نحوّله من陌生人 لـ customer؟"          │
│     (Channel-specific funnel)                    │
└─────────────────────────────────────────────────┘
```

**ليه القناة أولاً؟**
- كل قناة ليها **قوانينها** (organic vs paid، algo، restrictions)
- كل قناة ليها **تكلفتها** (CPL، time، risk)
- **لما تعرف القناة الصح، الـ persona بقى أسهل في الوصول**
- **والـ hook بقى طبيعي مش مفبرك**
