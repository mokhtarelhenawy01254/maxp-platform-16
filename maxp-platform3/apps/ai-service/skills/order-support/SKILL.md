# order-support

## متى تستخدم هذه الـ Skill
- العميل عايز يعرف حالة طلبه
- فيه مشكلة في الطلب (تأخير، منتج غلط، تتبع الشحن)
- العميل عايز يلغي أو يعدل طلب

## الأدوات المتاحة

### order_lookup
**امتى:** أول خطوة — اعرف تفاصيل الطلب
**إزاي:** مرر رقم الطلب بالظبط
**النتيجة:** تفاصيل الطلب الكاملة (المنتجات، السعر، الحالة، عنوان الشحن)
**ممنوع:** تقدم معلومات عن حالة الطلب بدون order_lookup

### shipping_rates
**امتى:** العميل يسأل عن تكلفة أو وقت الشحن
**إزاي:** مرر بيانات الشحن (العنوان، الوزن)
**النتيجة:** خيارات الشحن والتكلفة المتوقعة
**ممنوع:** تذكر سعر شحن بدون shipping_rates

### order_cancel
**امتى:** العميل يطلب إلغاء طلب وحالته "قيد التجهيز" أو "معلق"
**إزاي:** مرر رقم الطلب بعد التأكد من order_lookup إن حالته تسمح بالإلغاء
**ممنوع:** تلغي طلب تم شحنه بالفعل — لازم agent_handoff_to في الحالة دي

### shipping_update
**امتى:** العميل يريد تحديث عنوان الشحن أو بيانات التوصيل
**إزاي:** مرر رقم الطلب والبيانات الجديدة بعد order_lookup
**ممنوع:** تحدّث شحن طلب تم توصيله بالفعل

### agent_handoff_to
**امتى:** المشكلة معقدة ومحتاجة تدخل بشري (استرجاع كبير، شكوى، طلب مشحون ومحتاج إلغاء)
**إزاي:** مرر سبب التحويل والسياق الكامل
**النتيجة:** تحويل سلس لفريق الدعم

## خطوات التنفيذ
1. order_lookup لمعرفة تفاصيل الطلب الحالي
2. لو العميل يسأل عن الشحن -> shipping_rates
3. لو العميل يريد تحديث بيانات الشحن -> shipping_update
4. حدد نوع المشكلة وحالتها (قيد التجهيز، شحن، تم التوصيل)
5. اعرض الحلول المتاحة (تتبع، تعديل، إلغاء)
6. لو الطلب "قيد التجهيز" والعميل يريد إلغاء -> order_cancel
7. لو الطلب مشحون ويريد إلغاء -> agent_handoff_to
8. لو المشكلة معقدة -> agent_handoff_to لتحويلها

## ممنوعات
- لا تقدم معلومات عن حالة الطلب بدون order_lookup
- لا تذكر سعر شحن بدون shipping_rates
- لا تلغي طلب مشحون بدون agent_handoff_to
- لا تعد بحل بدون تفويض
- لا تتجاهل شكوى العميل
