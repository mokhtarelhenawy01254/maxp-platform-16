### CI Errors Encountered & Fixed (LESSONS LEARNED)

#### ❌ Error 1 — TypeScript `any` type violation
- **File**: `AppPricingSheet.tsx` line 178–179
- **Cause**: Used `let valA: any` and `let valB: any` in the sort function, which violates `@typescript-eslint/no-explicit-any` rule enforced by CI.
- **Fix**: Changed to `let valA: string | number` and `let valB: string | number`.
- **Rule to remember**: ⚠️ NEVER use `any` type in frontend TypeScript. Always define the narrowest correct union type.

#### ❌ Error 2 — ESLint `react-hooks/exhaustive-deps` warning
- **File**: `AppPricingSheet.tsx` line 83
- **Cause**: `useEffect` used `t` (translation function) inside its body but `t` was missing from the dependency array `[i18n.language]`.
- **Fix**: Added `t` to dependency array → `[i18n.language, t]`.
- **Rule to remember**: ⚠️ Always include ALL variables/functions used inside `useEffect` in its dependency array. ESLint treats this as an error in CI.

#### ❌ Error 3 — Documentation Compliance failure (`verify-docs.js`)
- **Cause**: Modified 4 source files (`AppPricingSheet.tsx`, `sidebar.ts`, `ar/subscription.json`, `en/subscription.json`) without creating/updating a corresponding `.md` doc file.
- **Fix**: Created `apps/frontend/docs/app-pricing-sheet-enhancements.md` documenting all changes.
- **Rule to remember**: ⚠️ The CI runs `node scripts/verify-docs.js` which BLOCKS push if any source code changes exist without a corresponding `docs/` update. Fix = either add a `.md` doc file OR add `[no-doc]` to the commit message.

#### ❌ Error 4 — Unstaged `translation.json` files blocking `git pull --rebase`
- **Cause**: The build step (`npm run build`) auto-generates merged `translation.json` files in `apps/frontend/src/locales/`. These were untracked/unstaged and blocked `git pull --rebase`.
- **Fix**: Staged them with `git add apps/frontend/src/locales/ar/translation.json apps/frontend/src/locales/en/translation.json` and included them in the commit.
- **Rule to remember**: ⚠️ After any i18n changes, always stage and commit the auto-generated `translation.json` files before pulling or pushing.

### Pre-Push Checklist (MANDATORY from now on)
Before every `git push` on the frontend:
1. `npx eslint src/pages/<changed-file>.tsx` → must be 0 errors
2. `npm run build` → must succeed (also merges i18n)
3. `git add apps/frontend/src/locales/*/translation.json` → stage auto-generated files
4. Ensure a `docs/` file exists for the changes OR add `[no-doc]` to commit message
5. `git pull --rebase` → then `git push`
