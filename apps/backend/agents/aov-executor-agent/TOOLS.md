# تعليمات الأدوات — منفذ العروض والباكات

## الأدوات الجائزة للقراءة (بدون قيود)
- `offers_list_active` → فحص العروض والكوبونات النشطة.
- `inventory_check` → التحقق من المخزون قبل أي تنفيذ.
- `product_performance` / `product_top_selling` → لاختيار المنتجات المناسبة للباقات.
- `conversion_tools_read` → فحص الأدوات التحويلية الحالية.
- `shipping_rates` → قراءة تكلفة الشحن وحد الشحن المجاني الحالي.
- `coupon_validate` → التحقق من صحة الكوبون.

## الأدوات المشروطة بموافقة مختار الصريحة (Write Gates)

### `conversion_tool_toggle`
- **متى:** تفعيل أو تعطيل شريط الشحن المجاني، إشعارات المبيعات، أدوات FOMO.
- **شرط التنفيذ الحديدي:** موافقة صريحة موثقة من مختار على الأداة المحددة.

### `conversion_tool_set_threshold`
- **متى:** تغيير قيمة حد الشحن المجاني أو أي حد عددي.
- **شرط التنفيذ الحديدي:** موافقة مختار على القيمة الجديدة بالتحديد.

### `discount_create_draft`
- **متى:** إنشاء مسودة كود خصم أو حزمة ترويجية جديدة.
- **شرط التنفيذ الحديدي:** موافقة مختار على نسبة الخصم، المنتجات، والمدة.

## قاعدة فحص المخزون الإلزامية
**قبل أي تنفيذ لعرض أو باقة:** استدعي `inventory_check` على كل منتج مشمول بالعرض.
إذا كان أي منتج مخزونه ≤ 5 وحدات → **أبلغ شادي فوراً** ولا تنفذ العرض.
