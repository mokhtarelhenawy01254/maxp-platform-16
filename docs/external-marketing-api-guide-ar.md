# دليل واجهة API الخارجية لوكلاء وبوتات التسويق — MaxP (External Marketing API)

دليل هندسي وعملي لفريق التسويق والوكلاء البرمجيين (AI Marketing Agents & Bots) لاستخدام واجهة الـ API الخارجية لقراءة وتحليل بيانات المنصة بصلاحيات كاملة وتحكم مركزي آمن.

---

## 1. ما هي واجهة الـ API الخارجية؟

واجهة برمجية موحدة وآمنة بنظام المفاتيح المشفرة (`X-API-Key` أو `Authorization: Bearer`) تسمح للبوتات ووكلاء الذكاء الاصطناعي على أجهزة أو خوادم أخرى بقراءة إحصائيات المنصة الحية دون الحاجة إلى استخدام المتصفح أو واجهة المستخدم الرسومية.

### 🛡️ مبادئ الأمان والخصوصية الصارمة:
1. **إجماليات وتجميع فقط (Zero PII):** الواجهة لا تُعيد نهائيًا أي بيانات شخصية تخص العملاء (ممنوع تمامًا رجوع أرقام الهواتف، البريد الإلكتروني، الأسماء، أو العناوين التفصيلية).
2. **تخزين المفاتيح المشفرة فقط (Hashing):** المفتاح الأصلي يظهر مرة واحدة فقط عند الإنشاء في السوبر أدمن، ولا يتم تخزين سوى الـ SHA256 Hash.
3. **تاريخ انتهاء إجباري:** كل مفتاح له تاريخ انتهاء صلاحية محدد لا يمكن تركه مفتوحًا إلى الأبد.
4. **سجل تدقيق غير قابل للتعديل (Immutable Audit Log):** كل طلب يتم توثيقه مع المسار، الوقت، كود الرد، عنوان IP، وزمن الاستجابة.
5. **محدد معدل الطلبات (Rate Limiting):** 60 طلب لكل دقيقة لكل مفتاح (يتم إرسال ترويسات `X-RateLimit-*`).
6. **زر إلغاء فوري (Kill Switch):** يمكن للسوبر أدمن إيقاف أي مفتاح فورًا ورفض أي طلب قادم بكود `401 Unauthorized`.

## 2. كيفية إنشاء مفتاح لوكيل تسويقي (Bot)

من لوحة **السوبر أدمن** (`/super-admin/external-api`):
1. اضغط على زر **«إنشاء مفتاح جديد»**.
2. أدخل **اسم المفتاح** ووسم تعريفي (مثال: `Facebook-Campaign-Agent-01`).
3. حدد **الشركة المستهدفة** (أو اتركها فارغة للوصول على مستوى المنصة كلها إذا كان المفتاح خاصًا بإدارة النظام).
4. حدد **تاريخ انتهاء الصلاحية** (إجباري).
5. (اختياري) حدد **قائمة عناوين IP المسموح بها** (IP Allowlist) لحصر استخدام المفتاح على خوادم أو أجهزة محددة.
6. اختر **السكوبات المطلوبة** (انظر المقترح أدناه).
7. اضغط **«توليد المفتاح الآن»**، وانسخ المفتاح السري فورًا واحفظه في مكان آمن، لأنه لن يظهر مجددًا.

## 3. السكوبات المتاحة (Scopes)

| السكوب | الوصف |
| :--- | :--- |
| `analytics:read` | قراءة ملخص الإيرادات، عدد الطلبات، متوسط قيمة الطلب، والمبيعات حسب المصدر. |
| `orders:read` | قراءة إجماليات وتوزيعات الطلبات وحالاتها. |
| `products:read` | قراءة قائمة المنتجات الأكثر مبيعًا والكميات والإيرادات المحققة. |
| `subscriptions:read` | قراءة إحصائيات الاشتراكات، الإيراد الشهري المتكرر (MRR)، والتجديدات. |
| `landing:read` | إحصائيات صفحات الهبوط، الزيارات، الطلبات، ونسبة التحويل لكل صفحة. |
| `leads:read` | قراءة أعداد وتصنيفات العملاء المحتملين وقنوات الاكتساب. |
| `customers:read` | إجماليات وتصنيفات العملاء (بدون بيانات شخصية). |
| `ads:read` | قراءة ميزانيات وحملات الإعلانات المربوطة. |
| `platform:read` | قراءة بيانات المنصة بالكامل عبر كافة الشركات (مخصص لإدارة النظام). |
| `*` | **صلاحية كاملة** لجميع المسارات الخارجية. |
| `tasks:read` / `write` | قراءة وتحديث مهام النظام (السكوبات السابقة وتظل متوافقة بالكامل). |

### 💡 السكوب الافتراضي المقترح لفريق ووكلاء التسويق:
```text
analytics:read, orders:read, products:read, landing:read, leads:read, subscriptions:read
```

## 4. نقاط النهاية المتاحة (Endpoints)

جميع المسارات تبدأ بـ `/api/v1/external/*`:

### 1) ملخص التحليلات العامة
```http
GET /api/v1/external/analytics/summary?from=2026-01-01&to=2026-10-01
```
- **السكوب المطلوب:** `analytics:read` أو `*`
- **البيانات المسترجعة:** إجمالي الإيراد (`totalRevenue`)، عدد الطلبات (`totalOrders`)، متوسط قيمة الطلب (`averageOrderValue`)، العملاء الجدد (`newCustomers`)، العملاء المتكررين (`returningCustomers`)، وتوزيع الحالات.

### 2) الطلبات والإيرادات حسب المصدر
```http
GET /api/v1/external/analytics/orders-by-source?from=2026-09-01
```
- **السكوب المطلوب:** `analytics:read` أو `*`
- **البيانات المسترجعة:** المبيعات مجمعة حسب المصدر (Facebook Inbox AI، Storefront، Cashier POS، يدوي...).

### 3) المنتجات الأكثر مبيعًا
```http
GET /api/v1/external/products/top?limit=10
```
- **السكوب المطلوب:** `products:read` أو `*`
- **البيانات المسترجعة:** قائمة بأفضل المنتجات مع الكميات المباعة وإجمالي الإيراد.

### 4) ملخص الاشتراكات و MRR
```http
GET /api/v1/external/subscriptions/summary
```
- **السكوب المطلوب:** `subscriptions:read` أو `*`
- **البيانات المسترجعة:** الـ MRR، المشتركين النشطين، فترات التجربة، والتجديدات القادمة.

### 5) إحصائيات صفحات الهبوط
```http
GET /api/v1/external/landing-pages/stats
```
- **السكوب المطلوب:** `landing:read` أو `*`
- **البيانات المسترجعة:** الزيارات، الطلبات، ونسبة التحويل (`conversionRate%`) لكل صفحة هبوط.

### 6) ملخص العملاء المحتملين (Leads)
```http
GET /api/v1/external/leads/summary
```
- **السكوب المطلوب:** `leads:read` أو `*`
- **البيانات المسترجعة:** أعداد الليدز حسب التقييم (VIP، Good...) وقنوات التواصل (فيسبوك، انستجرام، واتساب...).

### 7) ملخص الإعلانات والحملات
```http
GET /api/v1/external/ads/summary
```
- **السكوب المطلوب:** `ads:read` أو `*`
- **البيانات المسترجعة:** إحصائيات الحملات والميزانيات المستهلكة.

### 8) التوثيق البرمجي التفاعلي
```http
GET /api/v1/external/docs
```
- يعيد هيكل JSON كامل يشرح كل مسار، السكوبات المطلوبة، وأمثلة استدعاء جاهزة.

## 5. أمثلة الاستدعاء برمجياً

### عبر cURL:
```bash
curl -H "X-API-Key: ext_your_key_here" \
     "https://maxp.online/api/v1/external/analytics/summary"
```

### عبر Python:
```python
import requests

API_KEY = "ext_your_key_here"
BASE_URL = "https://maxp.online/api/v1/external"

headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
}

response = requests.get(f"{BASE_URL}/analytics/summary", headers=headers)
data = response.json()
print("Total Revenue:", data["data"]["totalRevenue"])
print("Total Orders:", data["data"]["totalOrders"])
```

### عبر Node.js:
```javascript
const apiKey = 'ext_your_key_here';
const res = await fetch('https://maxp.online/api/v1/external/products/top?limit=5', {
  headers: {
    'X-API-Key': apiKey
  }
});
const result = await res.json();
console.log('Top Products:', result.data.products);
```
