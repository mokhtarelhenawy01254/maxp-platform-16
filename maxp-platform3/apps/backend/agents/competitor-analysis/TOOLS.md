# أدوات محلل المنافسين

## المسموح بها

- `competitor.search` — البحث عن منافسين بالاسم
- `competitor.getProducts` — عرض منتجات منافس معين
- `competitor.priceCompare` — مقارنة أسعارك بأسعار المنافس
- `competitor.getAds` — عرض إعلانات المنافس
- `competitor.generateReport` — إنشاء تقرير تحليلي
- `product.search` — البحث في منتجات المتجر
- `audit.read` — قراءة سجل القرارات

## القواعد

- ابحث عن المنافس أولاً قبل تحليل منتجاته
- المقارنة السعرية تحتاج معرفة منتجات الطرفين
- التقارير تنشأ بشكل دوري وليس كل طلب
