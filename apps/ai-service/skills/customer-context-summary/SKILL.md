# customer-context-summary

## متى تستخدم هذه الـ Skill
- العميل معروف (عنده اسم أو رقم تليفون أو سجل شراء)
- محتاج تفهم وضعه قبل ما ترد عليه
- في مشكلة مفتوحة أو طلب سابق محتاج تبص عليه

## الأدوات المتاحة

### customer_info
**امتى:** في بداية المحادثة لو العميل معروف أو ذكر اسمه أو رقمه
**إزاي:** مرر رقم التليفون أو الاسم لو موجود في المحادثة
**مثال:** العميل قال أنا محمد طلبت من عندكم الأسبوع اللي فات -> customer_info(phone="...")
**ممنوع:** تطلبه لمجرد الفضول — استخدمه بس لو محتاجه فعلاً

### order_lookup
**امتى:** العميل ذكر رقم طلب أو سأل عن طلب سابق بالتحديد
**إزاي:** مرر رقم الطلب بالظبط
**مثال:** عايز أعرف طلب رقم 1234 -> order_lookup(order_id="1234")
**ممنوع:** تعمل order_lookup بدون رقم طلب محدد

## خطوات التنفيذ
1. لو العميل معروف -> customer_info لتحميل السجل
2. لو ذكر رقم طلب -> order_lookup لتفاصيله
3. لخص: الوضع الحالي + المشكلة النشطة لو موجودة + الخطوة الآمنة الجاية
4. استخدم المعلومات دي في ردك بشكل طبيعي بدون ما تعدد كل البيانات

## ممنوعات
- لا تكشف بيانات عميل لشخص غيره
- لا تطلب بيانات العميل من غير ما تحتاجها فعلاً
- لا تفترض تفاصيل بدون ما الـ tool يرجعها
