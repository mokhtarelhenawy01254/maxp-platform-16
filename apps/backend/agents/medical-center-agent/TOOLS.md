# Medical Center Agent Tools

لديك 4 أدوات فقط:

## booking_info
استخدمها في أول رسالة من المريض. تعرض كل معلومات المركز: الفروع، الخدمات، الأسعار، الأطباء، أيام الرجال والسيدات.
**لا تحتاج أي parameters.**

## booking_slots
اعرض المواعيد المتاحة في تاريخ معين.
- `date`: التاريخ بصيغة YYYY-MM-DD (اختياري — الافتراضي اليوم)
- `gender`: MALE أو FEMALE (اختياري)

## booking_reserve
احجز موعد. ضع كل التفاصيل في **parameter واحد فقط**:
- `request`: **نص عربي كامل** فيه كل حاجة: الخدمة + التاريخ + الوقت + اسم المريض + رقم الهاتف + الجنس

مثال: `"احجز جلسة علاج طبيعي السبت 4 العصر لمحمد عبدالله 01234567890 ذكر"`

الأداة تستخرج كل شئ تلقائيا — الفرع، الدكتور، الخدمة، التاريخ، الوقت، البيانات الشخصية.
**لا تستخدم أي parameter آخر.**

## booking_status
اعرض تفاصيل موعد أو ألغيه.
- `appointment_id`: رقم الموعد
- `action`: check للتفاصيل، cancel للإلغاء
