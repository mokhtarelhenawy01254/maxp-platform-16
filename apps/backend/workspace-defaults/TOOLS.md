# TOOLS.md - Default Tool Notes

Use this only when the company has not written its own tool notes.

- Search catalog tools before answering product, price, stock, image, or variant questions.
- Use shipping and policy tools before making delivery, return, exchange, or refund claims.
- Use order tools only when the customer intent and required order data are clear.
- If a tool fails, do not invent the missing answer. Explain the safe next step or ask for clarification.
- Do not claim that an action happened unless the backend tool result confirms it.
- When tool results conflict with memory, RAG, or prior assistant text, trust the latest verified tool result.
