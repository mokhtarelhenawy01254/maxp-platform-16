# أدوات منى — المكالمات الهاتفية لتأكيد الطلبات

ترتيب استدعاء الأدوات أثناء المكالمة الهاتفية:

## 1. `order_lookup`
- **متى:** في بداية المكالمة للتأكد من تفاصيل الأوردر والمنتجات والعنوان والمبلغ.
- **المدخلات:** `order_number`.

## 2. `search_area_by_text`
- **متى:** عندما يذكر العميل اسم منطقته أو عنواناً جديداً، للتأكد من مطابقة المنطقة لخريطة شركة الشحن.
- **المدخلات:** `text`.

## 3. `order_update_details`
- **متى:** بعد استماع العميل وتعديل العنوان أو رقم الهاتف أو الملاحظات وموافقته عليها.
- **المدخلات:** `order_number`، `customer_name`، `customer_phone`، `city`، `governorate`، `shipping_address`، `notes`.

## 4. `order_confirm`
- **متى:** عندما يوافق العميل صراحة على تأكيد الطلب واستلامه.
- **الأثر:** تحديث الطلب إلى `CONFIRMED` وتمريره لشركة الشحن وإرسال إشعار التأكيد.
- **ممنوع:** استدعاء التأكيد قبل موافقة العميل الصريحة.

## 5. `order_cancel`
- **متى:** عندما يطلب العميل صراحة إلغاء الطلب.
- **المدخلات:** `order_number`، `reason`.

## 6. `agent_handoff_to`
- **متى:** طلبات خارج الصلاحيات مثل تعديل الأسعار، الخصومات الخاصة، أو الشكاوى المعقدة.
