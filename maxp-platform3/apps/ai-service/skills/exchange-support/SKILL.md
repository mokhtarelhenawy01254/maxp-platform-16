# exchange-support

## متى تستخدم هذه الـ Skill
- العميل عايز يستبدل أو يرجع منتج
- فيه مشكلة في الطلب وعايز يحله
- عايز يعرف حالة الاسترجاع أو الاستبدال

## الأدوات المتاحة

### order_lookup
**امتى:** أول خطوة — اعرف تفاصيل الطلب الأصلي
**إزاي:** مرر رقم الطلب
**النتيجة:** تفاصيل الطلب الكاملة (المنتجات، السعر، الحالة)
**ممنوع:** تبدأ إجراء استبدال بدون رقم طلب محدد

### customer_info
**امتى:** عشان تعرف تاريخ العميل وطلباته السابقة
**إزاي:** مرر رقم الموبايل أو الاسم
**النتيجة:** بيانات العميل وتقييمه وعدد الطلبات
**ممنوع:** تستخدم بيانات العميل لأغراض تانية

### agent_handoff_to
**امتى:** لما المشكلة معقدة أو محتاج تدخل بشري
**إزاي:** مرر اسم الأجنت المناسب وسبب التحويل
**النتيجة:** تحويل سلس مع السياق

## خطوات التنفيذ
1. order_lookup لمعرفة تفاصيل الطلب الأصلي
2. customer_info لفهم تاريخ العميل
3. حدد نوع المشكلة (منتج خاطئ، عيب، تغيير رأي)
4. لو المشكلة بسيطة — اعرض حلول واضحة (استبدال، استرجاع)
5. لو المشكلة معقدة — agent_handoff_to لتحويل لفريق الدعم المتخصص
6. تابع مع العميل حتى يتأكد إن المشكلة اتحلت

## ممنوعات
- لا تعد العميل باسترجاع بدون ما تعرف سياسة المتجر
- لا تحول لأجنت تاني بدون ما توضح للعميل
- لا تكشف بيانات العميل لطرف تالت
- لا تتجاهل شكوى العميل — لازم ترد
