# catalog-search

## متى تستخدم هذه الـ Skill
- العميل يسأل عندك ايه او ايه المنتجات المتاحة
- العميل يسأل عن منتج بالاسم أو الوصف
- العميل يسأل عن مقاس أو لون معين
- تحتاج تتحقق من توفر منتج قبل ما توعد العميل بأي حاجة

## الأدوات المتاحة

### product_search
**امتى:** لما العميل يسأل عن منتج أو يطلب عرض الكتالوج
**إزاي (كتالوج كامل):** مرر query فارغ أو list_all=true لعرض كل المنتجات مع الفئات والأسعار والمتغيرات
**إزاي (منتج محدد):** مرر كلام العميل بالظبط كـ query بدون تعديل
**مثال:** العميل قال عايز حذاء أبيض -> product_search(query="حذاء أبيض")
**ممنوع:** تخترع سعر أو مخزون لو الـ tool ما ردتش بيه

### inventory_check
**امتى:** لما العميل يسأل في مقاس 42 او اللون الأسود موجود
**إزاي:** مرر اسم المنتج + المقاس + اللون المطلوب
**مثال:** في مقاس 40 لون أبيض -> inventory_check(product="...", size="40", color="أبيض")
**ممنوع:** تقول موجود أو مش موجود قبل ما تعمل الـ call

### offers_list_active
**امتى:** لما العميل يسأل عن العروض أو التخفيضات الشغالة حالياً
**إزاي:** استخدمها من غير أي مدخلات
**مثال:** عندك عروض؟ -> offers_list_active()
**ملاحظة:** بتجيب كل العروض في آن واحد (عروض المتجر، كوبونات، شحن مجاني)

### coupon_validate
**امتى:** لما العميل عنده كود خصم وعايز يتأكد من صحته وقيمته
**إزاي:** مرر الكود وقيمة الطلب
**مثال:** كود SAVE10 -> coupon_validate(code="SAVE10", order_amount="500")
**ممنوع:** تقول الكوبون صح أو غلط قبل ما تستخدم الـ tool

## خطوات التنفيذ
1. لو العميل سأل عن الكتالوج كله -> product_search(query="")
2. لو سأل عن منتج معين -> product_search(query="كلامه بالظبط")
3. لو سأل عن مقاس أو لون محدد -> inventory_check
4. لو سأل عن العروض أو التخفيضات -> offers_list_active
5. لو عنده كود خصم -> coupon_validate
6. اعرض: اسم، سعر، الألوان والمقاسات المتاحة فقط
7. لو العميل غير المنتج -> امسح الـ context القديم وابدأ search جديد

## ممنوعات
- لا تخترع سعر أو مخزون أو ميعاد توصيل
- لا تفترض توفر مقاس أو لون قبل inventory_check
- لا تعرض منتجات مش موجودة في نتيجة الـ tool
