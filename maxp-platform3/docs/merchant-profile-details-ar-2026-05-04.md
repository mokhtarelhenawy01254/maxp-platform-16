# صفحة ملف التاجر المستقلة

## الهدف

توحيد تجربة الشركة في متابعة الشركاء: مثلما أصبح للمسوق صفحة ملف مستقلة، أصبح للتاجر ملف مستقل على:

- `/merchants/:id` لعرض التاريخ والتفاصيل
- `/merchants/:id/edit` لتعديل بيانات التاجر وربط المنتجات والمزامنة

## ما تم تنفيذه

- إضافة API جديد: `GET /api/v1/merchants/:id/profile`
- الصفحة تعرض بيانات الحساب وحالة مستخدم التاجر إن وجد.
- الصفحة تعرض إعدادات التشغيل: مسار التنفيذ، التنفيذ التلقائي، المخزن الافتراضي، شركة الشحن، وWebhook.
- الصفحة تعرض ملخصات مالية ومخزنية: المتاح للسحب، العمولات المؤكدة، الرصيد المتاح، المحجوز، والطلبات.
- الصفحة تعرض تاريخ طلبات التاجر المرتبطة بالمسار الموحد للطلبات.
- الصفحة تعرض سجل عمولات التاجر وسجل طلبات السحب.
- الصفحة تعرض المنتجات والمخازن المرتبطة بالتاجر.
- قائمة التجار لم تتغير: زر العرض يفتح الملف الجديد، وزر التعديل يفتح شاشة الإدارة القديمة.
