# catalog-search — بحث الكتالوج واكتشاف المنتجات

## متى تستخدم هذه الـ Skill
- العميل يسأل "عندكوا ايه؟" أو "ابعتلي الكتالوج" أو "عايز أشوف المنتجات"
- العميل يسأل عن منتج بالاسم أو الوصف أو الـ SKU
- العميل يسأل عن مقاس أو لون معين
- العميل **بعت صورة** منتج عايز زيه أو شبهه
- العميل بيرجع لمنتج اتكلمتم عليه قبل كده ("عايز ده بس بلون تاني")
- العميل يسأل عن الأسعار أو العروض أو الخصومات
- العميل عنده كود خصم وعايز يتحقق منه
- تحتاج تتحقق من توفر منتج قبل ما توعد العميل بأي حاجة

---

## الأدوات المتاحة

### product_search
**الوظيفة:** بحث شامل في كتالوج المنتجات — يدعم: نص، كلمات مفتاحية، صور، فلترة بمقاس/لون.

**كل الـ Parameters:**
| Parameter | النوع | الوصف |
|:---|:---|:---|
| `query` | نص (مطلوب) | كلمة البحث — مرر كلام العميل بالظبط بدون تعديل. اتركه فارغ مع `list_all=true` لعرض الكتالوج كامل |
| `list_all` | bool | `true` لعرض كل المنتجات بدون فلترة — استخدمه لما العميل يقول "عندكوا ايه" |
| `limit` | رقم | عدد النتائج (افتراضي 5). استخدم 20+ مع `list_all`. لا تتجاوز 20 في البحث العادي |
| `product_size` | نص | فلتر المقاس — لو العميل حدد مقاس، مرره هنا (مثال: "42", "XL", "لارج") |
| `product_color` | نص | فلتر اللون — لو العميل حدد لون، مرره هنا (مثال: "أسود", "أبيض", "red") |
| `image_url` | نص | **بحث بالصورة** — لو العميل بعت صورة منتج عبر رابط، مرره هنا |
| `image_bytes` | نص | **بحث بالصورة** — لو الصورة وصلت كـ base64 encoded bytes |
| `mime_type` | نص | نوع الصورة (مثال: `image/jpeg`, `image/png`) — مطلوب مع `image_bytes` |
| `references_previous_product` | bool | `true` فقط لما العميل بيشير لمنتج سابق ("عايز ده"، "بكام ده"، "في لون تاني؟") |
| `use_vector` | bool | افتراضي `true` — يفعّل البحث الدلالي (semantic) كـ fallback لو النصي ما لقاش |

**أمثلة استدعاء:**
```
# بحث نصي عادي
product_search(query="حذاء رياضي")

# بحث مع فلتر مقاس ولون
product_search(query="تيشيرت", product_size="L", product_color="أسود")

# عرض الكتالوج كامل
product_search(query="", list_all=true, limit=20)

# بحث بالصورة
product_search(query="", image_url="https://...", use_vector=true)

# العميل بيرجع لمنتج سابق
product_search(query="عايز ده بلون أبيض", references_previous_product=true, product_color="أبيض")
```

### inventory_check
**الوظيفة:** فحص المخزون بالتفصيل — المقاسات والألوان المتاحة لمنتج معين.

**امتى:** لما العميل يسأل "في مقاس 42؟" أو "اللون الأسود موجود؟" أو "ده متوفر؟"
**إزاي:** مرر اسم المنتج + المقاس + اللون المطلوب
**مثال:**
```
inventory_check(product_name_or_sku="Nike Air Max", size="42", color="أبيض")
```
**ممنوع:** تقول "موجود" أو "مش موجود" قبل ما تعمل الـ call — لازم تتأكد الأول.

---

### offers_list_active
**الوظيفة:** جلب كل العروض والتخفيضات الشغالة حالياً من 5 مصادر موحدة:
1. الكوبونات النشطة بالكامل عبر الترقيم الصفحي (`coupons`).
2. عرض المتجر الترويجي الشامل للشرائح (`storePromotion`).
3. إعدادات الشحن المجاني والحد الأدنى للطلب (`promotionSettings`).
4. أدوات التحويل وباقات «اشترِ معًا» وسويت التحويل من إعدادات المتجر العامة (`storefrontSettings`).
5. عروض وخصومات الكميات والخصم المباشر لأسعار المنتجات (`productOffers`).

**المعاملات:**
- `include_all_coupons`: boolean (افتراضي `false`). في الوضع الافتراضي عند وجود أكثر من 10 كوبونات نشطة يتم تقديم ملخص ذكي بالأعداد والحملات والأنواع مع نماذج للأكواد. مرر `true` فقط إذا طلب التاجر صراحة سرد كافة الأكواد بالكامل.

**ضوابط الرد الإلزامية:**
- **للعملاء والمتسوقين:** اعرض العروض والخصومات المتاحة بأسلوب بيعي جذاب ومباشر (نسبة الخصم، كود الخصم، حد الشحن المجاني، عروض الكميات). **يُمنع منعاً باتاً ذكر إحصائيات تقنية داخلية للمتسوق مثل إجمالي عدد الكوبونات (مثل: «عندنا 44 كوبون») أو عدد الحملات (مثل: «مجمعة في 4 حملات») أو أسماء مصادر البيانات البرمجية ومصادر القراءة والفشل.**
- **منع الفشل الصامت:** إذا تعذر جلب أي مصدر، اعتمد على بقية المصادر التي نجحت ولا تقل للعميل «لا توجد عروض» أو «مفيش بيانات».
- **للتاجر والتقارير الإدارية فقط:** يمكن عرض الملخص الإحصائي بالأعداد وتوزيع الحملات والمصادر المقروءة.
**امتى:** لما يسأل العميل أو التاجر "في عروض؟" أو "هات كل العروض الشغالة".
**إزاي:** `offers_list_active()` أو `offers_list_active(include_all_coupons=true)` عند طلب كل الأكواد بالتفصيل.

### coupon_validate
**الوظيفة:** التحقق من صحة كود خصم وحساب قيمة الخصم.
**امتى:** لما العميل يقول "عندي كود SAVE10" أو "الكود ده شغال؟"
**إزاي:** مرر الكود وقيمة الطلب التقديرية.
**مثال:**
```
coupon_validate(code="SAVE10", order_amount="500")
```
**ممنوع:** تقول "الكود صح" أو "غلط" قبل ما تستخدم الـ tool.

---

### product_top_selling
**الوظيفة:** أكثر المنتجات مبيعاً في فترة معينة.
**امتى:** لما العميل يقول "ايه الأكثر طلباً" أو لما البحث ما رجعش نتائج وتحتاج تعرض بدائل.
**إزاي:**
```
product_top_selling(period="month", limit=5)
```

---

### category_list
**الوظيفة:** قائمة كل الأقسام/الفئات المتاحة مع عدد المنتجات في كل قسم.
**امتى:** لما العميل يسأل "ايه الأقسام عندكوا" أو تحتاج تساعده يختار فئة.

## شجرة القرار (Decision Tree)

اتبع هذا التسلسل عند كل تفاعل بحث:

```
العميل طلب منتج
├── هل بعت صورة؟
│   └── نعم → product_search(image_url=..., use_vector=true)
├── هل حدد اسم/وصف؟
│   ├── نعم + حدد مقاس → product_search(query=..., product_size=...)
│   ├── نعم + حدد لون → product_search(query=..., product_color=...)
│   ├── نعم + مقاس ولون → product_search(query=..., product_size=..., product_color=...)
│   └── نعم فقط → product_search(query=...)
├── هل بيرجع لمنتج سابق؟ ("عايز ده"، "بكام ده")
│   └── نعم → product_search(query=..., references_previous_product=true)
├── هل عايز يشوف الكتالوج كله؟
│   └── نعم → product_search(query="", list_all=true, limit=20)
└── هل عايز يشوف الأقسام؟
    └── نعم → category_list()
```

### معالجة النتائج:
```
النتائج رجعت
├── 0 نتائج
│   ├── اعتذر بلطف: "مش لاقي المنتج ده بالظبط"
│   ├── استخدم product_top_selling() لعرض بدائل شائعة
│   └── اسأل العميل: "تحب أعرضلك حاجات مشابهة؟"
├── 1-3 نتائج
│   └── اعرضهم بالتفصيل: اسم + سعر + الألوان/المقاسات المتاحة + صورة
├── 4+ نتائج
│   ├── اعرض أول 3 فقط
│   └── قول: "عندي كمان خيارات تانية — تحب تشوفهم؟"
└── خطأ تقني / timeout
    ├── ❌ ممنوع تقول "حصلت مشكلة تقنية"
    ├── ✅ قول: "ثانية واحدة بتأكد من المتوفر..."
    └── حاول مرة تانية — لو فشل تاني، صعّد لدعم بشري
```

## تنسيق العرض للعميل

### عند عرض منتج واحد أو الرد على سؤال السعر:
- اذكر دائماً **سعر القطعة مع الخصم (`price` بدل `comparePrice`)** إن وجد.
- اذكر دائماً **عروض الكميات المتاحة على المنتج (`quantityOffers` / `offersSummary`)** مثل **عرض القطعتين وعرض الـ 3 قطع** بجانب السعر والخصم في نفس الرسالة (يطبق على كل المنتجات التي تحتوي على عروض كميات).
- اذكر الألوان والمقاسات المتاحة وحالة التوفر بأسلوب طبيعي ومترابط.

### عند عرض عدة منتجات:
- اعرض **2-3 منتجات كحد أقصى** — لا تغرق العميل.
- اربط كل منتج باحتياج العميل: "أنت بتدور على كوتشي؟ عندنا..."
- لو في عرض/خصم على المنتج أو عروض كميات (قطعتين / 3 قطع)، اذكرها فوراً.

### عند عدم وجود نتائج:
- لا تقول "مفيش" وتسكت.
- اعرض بدائل: `product_top_selling` أو اقترح فئة: `category_list`.
- مثال: "المنتج ده مش متوفر حالياً، بس عندي حاجات تانية ممكن تعجبك 😊"

## تعامل مع الصور (Visual Search)

لما العميل يبعت صورة منتج:
1. استقبل الصورة — هتوصلك كـ `image_url` أو `image_bytes` في الـ attachments.
2. استدعي `product_search` مع الصورة:
   - لو URL: `product_search(query="", image_url="<الرابط>", use_vector=true)`
   - لو bytes: `product_search(query="", image_bytes="<base64>", mime_type="image/jpeg", use_vector=true)`
3. لو لقيت نتائج بـ score عالي (> 0.7) → اعرضها بثقة.
4. لو لقيت نتائج بـ score متوسط (0.5-0.7) → اعرضها مع "ده أقرب حاجة عندنا ليها".
5. لو ما لقيتش (score < 0.5) → "مش لاقي المنتج ده بالظبط، بس ممكن أعرضلك حاجات مشابهة؟"

## ممنوعات صارمة

| ❌ ممنوع | ✅ البديل |
|:---|:---|
| تخترع سعر أو مخزون أو خصم | استخدم الأداة أولاً دايماً |
| تفترض توفر مقاس/لون قبل `inventory_check` | اعمل الـ call واتأكد |
| تعرض منتجات مش في نتيجة الأداة | اعتمد فقط على البيانات الراجعة |
| تقول "مش لاقي" وتسكت | اعرض بدائل أو اسأل العميل يوضح أكتر |
| تعرض أكتر من 3 منتجات مرة واحدة | اعرض 3 واقترح "تحب تشوف كمان؟" |
| تقول "حصلت مشكلة تقنية" | قول "ثانية بتأكد..." وحاول تاني |
| تتجاهل صورة بعتها العميل | استخدم `image_url` أو `image_bytes` في البحث |

## بعد إتمام البحث — الخطوة التالية

لما العميل يبدي اهتمام بمنتج، فكّر في:
- **هل يحتاج يعرف عن عروض؟** → `offers_list_active`
- **هل ممكن تقترح منتج مكمل (upsell)?** → المهارة `upsell-engine`
- **هل العميل مستعد يشتري؟** → انتقل لمهارة `deal-closing`
- **هل العميل اعترض على السعر؟** → انتقل لمهارة `smart-negotiation`
- **هل عنده عربة متروكة فيها منتج مشابه؟** → المهارة `cart-recovery`
