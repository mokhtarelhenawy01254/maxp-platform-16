1 محرر V4 — الجيل الجديد (Atomic Editor — أبريل 2026، مستقر منذ 4.3)

أكبر تحوّل في تاريخ إلمنتور: نظام «ذَرّي» (Atomic) مبني على CSS — كل عنصر = غلاف div واحد فقط، والأسلوب يُكتب مرة ويُعاد استخدامه في كل مكان.

🎨 المتغيرات Variables V4

تعريف الألوان والخطوط والأحجام مرة واحدة (primary-color, button-font…) وتطبيقها في كل الموقع — تعديل واحد يتسلسل للكل. مع Variables Manager لإدارة مركزية.

🏷️ الكلاسات Classes V4

مكتبة أنماط قابلة لإعادة الاستخدام + Class Manager (إعادة تسمية/حذف/ترتيب أولويات بالسحب) + States: هوفر / فوكس / أكتيف بدون كود + Draft Classes.

🧱 المكوّنات Components برو V4

حوّل أي حاوية لمكوّن متزامن في كل الموقع، مع تحديد أجزاء يُسمح بتعديلها لكل نسخة — وميزة Detach لفصل نسخة عن الأصل.

🖌️ تبويب الأنماط الموحّد V4

General + Style لكل العناصر الذرّية بنفس الشكل، وكل خاصية (بدون استثناء) قابلة للتعديل لكل جهاز من الشريط العلوي، مع Reset و Logical Properties وخلفيات متعددة الطبقات.

🎬 التفاعلات Interactions برو V4

مشغّلات حقيقية: عند التحميل / الظهور بالتمرير / هوفر / نقر — مع Custom Effect لتحديد التحوّل بنفسك، وإعداد مختلف لكل نقطة توقف.

5 التسويق والفورمز برو

🪟 Popup Builder

بوب-أب بكسل بيرفكت بالتصميم السحب والإفلات + مشغّلات (خروج، تمرير، تأخير، نقر…) + استهداف متقدم (صفحة/دولة/جهاز…) + قواعد (عدد مرات العرض، زائر جديد…) + مكتبة قوالب بوب-أب جاهزة.

📝 Form Builder

حقول متعددة (نص/إيميل/هاتف/ملف/تاريخ/موافقة…) + حماية سبام + reCAPTCHA + سجل الإرسالات داخل الموقع + تكاملات: Mailchimp، HubSpot، Slack، Zapier، Webhooks، وCRM — وAtomic Forms الجديدة في V4 (حقول كعناصر مستقلة).

📊 Dynamic Content

ربط التصميم بمحتوى ووردبريس: حقول مخصصة، ACF، حقول المنتجات — صفحة واحدةلكل عنصر تلقائيًا (Blog/متجر كبير بدون تكرار).

🗒️ أدوات مساعدة

ملاحظات تعاونية Collaborative Notes (إضافة تعليق لأي عنصر للمراجعة) + Element Manager (تعطيل ودجات مش مستخدمة + صلاحيات لكل دور) + المفضلة Favorites لتثبيت ودجاتك الأكثر استخدامًا.

7 الذكاء الاصطناعي 2026

🤖 Angie — وكيل AI داخل ووردبريس

مساعد إلمنتور الرسمي: يبني صفحات كاملة بالبرومبت، أنظمة تصميم (Classes وVariables)، فورمز، وحلقات Loop — ويعدّل ويحدّث محتوى موجود. أُضيف للمحرر في 4.2/4.3 وهو قلب «Build with prompts» في 2026.

✨ Elementor AI

توليد نصوص (وترجمتها وإعادة صياغتها وتصحيحها) + توليد وتحرير الصور + مساعد الكود (CSS/JavaScript/HTML) + AI Site Planner (بريف وخريطة موقع ووايرفريمز من فكرة) + AI Context يتعلم هوية نشاطك عشان المحتوى يطلع متسق.

🔌 Elementor MCP سبتمبر 2026

ربط موقعك بـ Claude وCodex وCursor وأدوات AI خارجية: يبنوا صفحات ويعدّلوا عناصر ويشتغلوا مع نظام التصميم — من خارج ووردبريس. (دعم V3 والمهارات المتخصصة MCP Skills: في الطريق Q4 2026).
