# handoff-to-human

## متى تستخدم هذه الـ Skill
- المشكلة معقدة ومحتاجة تدخل بشري مباشر
- العميل طلب يتكلم مع شخص حقيقي
- المشكلة خارج نطاق الأجنت (شكوى قانونية، خصم كبير، حالة استثنائية)

## الأدوات المتاحة

### agent_handoff_to
**امتى:** لما تحتاج تحول المحادثة لشخص أو أجنت تاني
**إزاي:** مرر سبب التحويل والسياق الكامل
**النتيجة:** تحويل سلس للمحادثة مع كل المعلومات
**ممنوع:** تحول بدون ما توضح السبب للمستخدم

## خطوات التنفيذ
1. حدد إن المشكلة فعلاً محتاجة تدخل بشري (مش هنتجرب نحلها أولاً)
2. لخص المشكلة والسياق للمستخدم
3. وضح ليه التحويل ضروري وإيه اللي هيحصل بعده
4. agent_handoff_to مع السياق الكامل (المشكلة، الطلبات السابقة، الحلول المقترحة)
5. تابع إن التحويل حصل بنجاح

## ممنوعات
- لا تحول المشكلة لأجنت مش متخصص فيها
- لا تسيب السياق — حوّل كل المعلومات المهمة
- لا تحول بدون ما توضح للمستخدم ليه
- لا تستخدم التحويل كحل أول — حاول تحل المشكلة الأول
