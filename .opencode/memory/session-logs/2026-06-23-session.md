## Harf WhatsApp Cloud Inbound Auto-Reply

- User reported that a fresh WhatsApp message to Harf did not receive a reply.
- Production DB showed no Harf `whatsapp_messages` rows after the send, so the failure was before AI response generation.
- Root causes found:
  - Meta app `Harfcrm` (`1688924222334388`) had no app-level `whatsapp_business_account/messages` webhook subscription.
  - `whatsappMetaWebhookController` filtered deleted sessions with `NOT metadata contains ...`, which excluded active sessions where `metadata = null`; this made callback verification return `403`.
- Fixed:
  - Allowed `metadata = null` as an active Meta session state while still excluding `metadata.isDeleted=true`.
  - Registered production Meta app callback `https://maxp.online/api/v1/whatsapp-meta` for `whatsapp_business_account/messages`.
  - Ensured WABA `1306119191241535` is subscribed to the app.
