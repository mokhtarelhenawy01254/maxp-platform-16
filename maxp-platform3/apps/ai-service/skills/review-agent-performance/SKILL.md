# review-agent-performance

## متى تستخدم هذه الـ Skill
- المدير يريد مراجعة أداء الأجنتم
- محتاج تقييم فعالية أجنت معين
- عايز يعرف إيه الأجنتم الشغالين كويس وإيه اللي محتاج تحسين

## الأدوات المتاحة

### audit_read
**امتى:** لجمع بيانات أداء الأجنتم من السجلات
**إزاي:** مرر نوع الحدث وفترة زمنية محددة
**النتيجة:** سجلات القرارات، الأخطاء، المهام المكتملة
**ممنوع:** تقيم أداء أجنت بدون بيانات من الـ tool

## خطوات التنفيذ
1. audit_read لجمع بيانات الأداء للفترة المطلوبة
2. حلل البيانات: المهام المكتملة، الأخطاء، وقت الاستجابة
3. لخص لكل أجنت: الأداء + المشاكل + التوصية
4. اقترح تحسين واحد واضح لو فيه مشكلة

## ممنوعات
- لا تقيم أداء بدون بيانات حقيقية
- لا تصدر حكم على أجنت بدون سياق كافي
- لا تقارن أجنتم بأدوار مختلفة — كل واحد له معاييره
