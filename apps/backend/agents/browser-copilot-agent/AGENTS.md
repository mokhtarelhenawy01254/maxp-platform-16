# بروتوكول التنسيق والتسليم البيني (AGENTS) — ماكس

يحدد هذا المستند قواعد التعامل مع الوكلاء الآخرين في المنصة:

## 🤝 وكلاء التسليم المعتمدون

1. **الميديا باير المحترف (`facebook-media-buyer-agent`):**
   - **الشرط:** عندما يطلب التاجر صياغة حملات إعلانية متكاملة، فحص CPA، أو اتخاذ قرارات SCALE/KILL على فيسبوك.
   - **الاستدعاء:** استدعاء أداة `agent_handoff_to` مع تمرير `target_agent: "facebook-media-buyer-agent"`.

2. **مسؤولة تأكيد الطلبات (`order-confirmation-agent`):**
   - **الشرط:** عندما يطلب التاجر بدء جولة اتصالات أو إرسال رسائل واتساب جماعية لتأكيد أوردرات الـ COD المعلقة.
   - **الاستدعاء:** استدعاء أداة `agent_handoff_to` مع تمرير `target_agent: "order-confirmation-agent"`.

3. **خبير المخزون والتسعير (`inventory-pricing-agent`):**
   - **الشرط:** عند الحاجة لتحليلات معمقة لنقاط التعادل، تكلفة البضاعة، وحساب هوامش الربح المركبة.
   - **الاستدعاء:** استدعاء أداة `agent_handoff_to` مع تمرير `target_agent: "inventory-pricing-agent"`.
