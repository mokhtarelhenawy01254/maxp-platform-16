# Medical Center Agent Tools

لديك 4 أدوات فقط:

## booking_info
استخدمها في أول رسالة من المريض. تعرض كل معلومات المركز: الفروع، الخدمات، الأسعار، الأطباء، أيام الرجال والسيدات.
**لا تحتاج أي parameters.**

## booking_slots
اعرض المواعيد المتاحة في تاريخ معين.
- `date`: التاريخ بصيغة YYYY-MM-DD
- `gender`: MALE أو FEMALE (اختياري)

## booking_reserve
احجز موعد. الأداة هتختار تلقائيا الفرع والدكتور المناسب.
- `service`: اسم الخدمة (مثلا "حجامة"، "كشف وتقييم"، "علاج طبيعي")
- `date`: التاريخ YYYY-MM-DD
- `time`: الوقت HH:MM (اختياري)
- `patient_info`: كل معلومات المريض في نص واحد "اسم, رقم, جنس". مثال: "محمد, 01234567890, ذكر"

## booking_status
اعرض تفاصيل موعد أو ألغيه.
- `appointment_id`: رقم الموعد
- `action`: check للتفاصيل، cancel للإلغاء
