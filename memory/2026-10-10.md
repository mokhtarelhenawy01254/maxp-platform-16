## Facebook OAuth Configuration & Credentials Resolution

- **Problem Reported:** User received "معرف التطبيق غير صالح" error in Facebook OAuth dialog popup on `https://maxp.online/settings/facebook-oauth`.
- **Root Cause:**
  - The OAuth popup URL had `client_id=&` because `getFacebookOAuthConfig()` returned an empty `appId`.
  - `/var/www/backend2/data/facebook-oauth-config.json` did not exist on production, and `.env` had placeholder `your-production-facebook-app-id` which was filtered out.
  - The OAuth routes (`/authorize`, `/ads-authorize`, `/reauthorize-consent`, `/pixel-authorize`) lacked validation for missing `appId`.
- **Resolution:**
  - Configured actual Meta App credentials provided by the user in `developers.facebook.com`:
    - **App Name:** `m2` (App ID: `762328696481583`)
    - **App Secret:** `9ef40d290082e1d2455ac38646f2b379`
    - **Graph API Version:** `v26.0` (managed dynamically via `getMetaGraphApiVersion()`)
    - **Redirect URI:** `https://maxp.online/api/v1/facebook-oauth/callback`
  - Created `/var/www/backend2/data/facebook-oauth-config.json` and persistent backup in `/var/www/shared/facebook-oauth-config.json`.
  - Added persistent restore logic in `scripts/deploy-remote.sh`.
  - Added validation guards in `apps/backend/routes/facebookOAuthRoutes.js`.
  - Verified with Meta Graph API `v26.0` and tested OAuth dialog endpoint: returns HTTP 302 redirecting to Meta login for App ID `762328696481583`.
