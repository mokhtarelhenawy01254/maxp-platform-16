## المطلوب (Fix spec)
**الملف الرئيسي:** `apps/frontend/src/storefront/pages/PostPurchaseOfferPage.tsx`

1. **منتَقي مجمّع (لون ← مقاس):**
   - التحليل: فضّل `variant.options`/metadata لو غير فاضية (حاليًا `{}` فاضية) → fallback من الاسم بـ regex `^(.*?)\s*-\s*(\d{1,3})$` → {colorLabel, sizeLabel}. **لو أي variant فشل تحليله → fallback كامل للعرض الحالي (flat chips) بدون كسر.**
   - **صف اللون:** "اختاري اللون" — chips بالألوان الفريدة بترتيب الظهور ("أبيض × أسود" / "أبيض × نبيتي")، المختار مظلّل emerald + علامة "✓" (نفس نمط PDP).
   - **صف المقاس:** "اختاري المقاس" — أرقام فقط للمقاسات المتاحة في اللون المختار، مرتّبة تصاعديًا، بعرض ثابت (`min-w-[44px] h-10`) — tap target مناسب للموبايل.
   - تغيير اللون: لو المقاس الحالي موجود في اللون الجديد → يفضل مختار (variant يتحل)، وإلا يُمسح المقاس.
   - الاختيار النهائي ⇒ `selectedVariant` = الفاريانت المطابق (الـid الصح في الـpayload).
2. **إزالة الاختيار الافتراضي:** احذف `setSelectedVariant(fetchedOffer.product.variants[0])` (أسطر ~84–90).
3. **تحصين الـCTA:** لو مفيش لون+مقاس مختارين → toast "اختاري اللون والمقاس الأول 🙏" + scroll للمنتقي + **منع أي API call** (variantId مش يتبعت null). ولو الفاريانت المختار stock <= 0 → toast ومنع كذلك.
4. **المخزون:** مقاس غير متاح (لا يوجد له variant أو stock <= 0) → disabled + باهت + line-through (بدون كسر التصميم).
5. **إخفاء شريط الشحن المجاني في صفحة العرض:** `apps/frontend/src/storefront/StorefrontShell.tsx` سطر ~1449: `{!isProductImageLandingPage ? <FreeShippingBar /> : null}` → إخفاء كذلك على مسار `/order-offer` (يوجد detection جاهز للـroute حوالي سطر 303: `normalizedPath.endsWith("/order-offer")`) — لأن "أضف 2,001ج للحصول على شحن مجاني" بيتناقض مع "شحن مجاني بالكامل" داخل العرض.
6. **نصوص:** الليبلات الجديدة "اختاري اللون" / "اختاري المقاس" (مؤنث — متسق مع هوية المتجر).
