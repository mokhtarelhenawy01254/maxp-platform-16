## 🔴 حرج

### 1. جداول الديسكتوب على الموبايل — /products و /customers
- جدول المنتجات: **عرض 1264px** على شاشة 360px (سحب أفقي بمقدار 4 شاشات)
- جدول العملاء: **عرض 1034px**
- الحاوية `overflow-x-auto` شغالة تقنيًا، لكن تجربة سحب جدول عريض بالإصبع على موبايل = تجربة فاشلة للوظيفة الأساسية.

**الإصلاح:** عرض بطاقات (cards) تحت `md:` بدل الجدول:
```tsx
{/* Hidden on mobile */}
<div className="hidden md:block">…الجدول الحالي…</div>
{/* Card list on mobile */}
<div className="md:hidden space-y-3">
  {products.map(p => <ProductCard key={p.id} product={p} />)}
</div>
```
حقل أساسي في البطاقة: صورة + اسم + سعر + حالة + زر أكشن رئيسي.

### 2. نص حالة مخفي بالكامل — /orders
بادج "مؤكد" ظهر في الفحص الأول بتباين **1:1** (نص = لون الخلفية) بحجم 12px. في زيارة المتابعة اختفى (الليست اتغيرت) — **عيب متقطع حسب البيانات**، في بعض حالات الطلبات النص مش شايفه أصلًا.
**الإصلاح:** راجع كلاسات بادجات الحالة — غالبًا `text-white` على خلفية فاتحة أو `bg-*` مش محمّلة:
```css
/* مثال للإصلاح — كل بادج حالة لازم يعدّي 4.5:1 */
.badge-confirmed { background: rgb(220, 252, 231); color: rgb(21, 128, 61); }  /* 4.8:1 */
```

### 3. أزرار أكشن أصغر من الحد الأدنى في كل حتة
| الصفحة | العنصر | المقاس | المطلوب |
|---|---|---|---|
| /apps (×29) | زر "إضافة للمفضلة" | **22×22** | ≥24، الأفضل 44 |
| /unified-inbox (×9) | أزرار أكشن الرسائل | **18×18** | ≥24 |
| /products | "عرض في المتجر" + أكشنات الصفوف | **16×16** | ≥24 |
| /customers | أكشنات صفوف العملاء | **16×16** | ≥24 |

كلها تحتها الحد الأدنى لـ WCAG 2.2 (24×24) — على الموبايل دي نقاط إحباط يومية.
```css
.row-action { width: 40px; height: 40px; display: inline-flex; align-items: center; justify-content: center; }
/* أو زوّد مساحة النقر حول الأيقونة */
```

## 🟠 متوسط

### 4. ليبلات KPI صغيرة وباهتة — /orders و /company-dashboard
- "إجمالي الطلبات"، "الإيرادات"، "متوسط قيمة الطلب": **10px بتباين 2.56**
- "نشط"، "متصل": **9px**
- "+100%"، "▲ 99 %": 10px

هذه أهم أرقام عند صاحب البيزنس — لازم تتشاف من غير سكوطة.
```css
.kpi-label { font-size: 12px; color: rgb(75, 85, 99); }  /* 4.8:1 على أبيض */
.kpi-value { font-size: 22px; }
```

### 5. أسعار المنتجات بتباين 2.54 — /products
"٦٨٩ ج.م"، "٩٠٠ ج.م"... (12px) — السعر أهم عنصر في صفحة منتجات للتجار.

### 6. ليبلات قناة "واتساب" بتباين 3.02 — /unified-inbox
مكرر في كل رسالة (10.88px) — يبان باهت في الليستة الطويلة.

### 7. فلاتر بلا aria-label — /products (14) و /customers (13)
selects وinputs من غير label ولا placeholder ولا title — قارئ الشاشة يقرأ "قائمة منسدلة" بس.
```tsx
<select aria-label="تصفية حسب الفئة">
```

### 8. شريط تصفية التطبيقات بلا مؤشر سكرول — /apps
9 فلاتر في صف قابل للسكرول أفقيًا (شيم shrink-0) من غير fade حافة يوحي بوجود المزيد.
