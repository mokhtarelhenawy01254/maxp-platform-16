# MaxP Copilot — إضافة المتصفح الذكية (Browser Extension)

إضافة متصفح رسمية لمنصة **MaxP** تعمل كـ Popup سريع ومساعد ذكي يرافق التاجر أو المستخدم أثناء تصفح أي موقع على الإنترنت.

---

## 🌟 الميزات الرئيسية

1. **الوصول الفوري للمساعد:**
   - ضغطة واحدة على أيقونة الإضافة في شريط أدوات المتصفح لفتح نافذة المساعد السريعة.
2. **سياق الصفحة الحالية (Active Tab Context):**
   - قراءة تلقائية لعنوان ورابط الصفحة الحالية وإرسالها للوكيل بضغطة زر عند الرغبة في تحليل صفحة معينة أو الاستفسار عنها.
3. **تكامل كامل مع وكلاء المنصة المتخصصين:**
   - **كريم — مدير تشغيل المتجر (`store-manager-agent`)**: متابعة الطلبات، المخزون، والعمليات اليومية.
   - **مساعد الدعم والاستفسارات (`support-agent`)**: إجابات سريعة وشروحات لخطوات المنصة.
   - **منى — تأكيد ومتابعة الطلبات (`order-confirmation-agent`)**: متابعة أوردرات COD ونسب التسليم.
   - **مساعد المخزون والتسعير (`inventory-pricing-agent`)**: مراقبة هوامش الربح ونقاط التعادل.
4. **أمان معزول بالكامل:**
   - التوثيق عبر JWT Token مع خوادم MaxP (`https://maxp.online` أو السيرفر المحلي).
   - سحب مفاتيح الذكاء الاصطناعي حصرياً من قاعدة بيانات `public.ai_keys` في السيرفر دون تخزين أي مفاتيح في كود الإضافة.

---

## 🚀 كيفية التثبيت والتجربة (Load Unpacked)

1. **بناء الحزمة:**
   ```bash
   cd apps/browser-extension
   npm install
   npm run build
   ```
2. **تحميل الإضافة في Google Chrome أو Microsoft Edge:**
   - افتح المتصفح وتوجه إلى `chrome://extensions` (أو `edge://extensions`).
   - فعّل **Developer mode** (وضع المطور) من الزاوية العلوية.
   - اضغط على زر **Load unpacked** (تحميل إضافة تم فك حزمتها).
   - اختر مجلد `apps/browser-extension/dist`.
3. **التشغيل:**
   - ستظهر أيقونة **MaxP Copilot** في شريط المتصفح العلوي.
   - اضغط على الأيقونة لتسجيل الدخول والبدء مباشرة!
