# تقرير إصلاحات إنتاج Swan / KHEMET LUXE

التاريخ: 2026-05-01
النطاق: متجر Flora/Swan على Production: `https://flora.maxp.online`

## السيناريوهات التي تم تشغيلها

- فتح صفحة المنتج المباشرة `/product/kotshy-soan` على الموبايل والكمبيوتر.
- اختبار روابط الهيدر: كل الأحذية، الكوتشيات، الفلات، العروض.
- اختبار منيو الموبايل والتنقل بدون Refresh.
- اختبار زر "ضيفيه للسلة" من صفحة المنتج.
- اختبار فتح السلة بعد الإضافة وظهور عداد السلة.
- اختبار وجود الأب سيل داخل السلة وعدم تعطيل CTA الدفع.
- اختبار المنتجات المقترحة بعد التمرير في صفحة المنتج.
- مراجعة Console أثناء السيناريوهات الأساسية.

## مشاكل تم اكتشافها

### P0 - زر إتمام الطلب خارج شاشة الموبايل

بعد الضغط على "ضيفيه للسلة" كانت السلة تفتح فعلا، لكن عند وجود منتجات مقترحة داخل السلة كان زر إتمام الطلب ينزل أسفل الشاشة على موبايل 390x844. هذا كان يمنع المستخدم من الوصول للدفع بسهولة ويكسر مسار التحويل من الإعلان إلى الطلب.

الإصلاح:

- تثبيت Header وFooter السلة خارج منطقة التمرير.
- نقل عناصر السلة والأب سيل إلى منطقة تمرير داخلية مستقلة.
- جعل زر إتمام الطلب ظاهرا دائما في Footer السلة.
- إعادة ضبط تمرير جسم السلة للأعلى عند فتحها أو تغيير عدد المنتجات.

الملف:

- `frontend/src/storefront/components/CartDrawer.tsx`

### P1 - ظهور سعر مقارنة صفر في المنتجات المقترحة

في منتجات "كمّلي الإطلالة" ظهر `EGP 0.00` كسعر قديم مشطوب لبعض المنتجات التي قيمة `comparePrice` لديها صفر. هذا يقلل الثقة ويظهر السعر كأنه خطأ.

الإصلاح:

- عرض سعر المقارنة فقط إذا كان رقما صالحا وأكبر من السعر الحالي.
- دعم الأسعار القادمة كأرقام أو نصوص رقمية.

الملف:

- `frontend/src/storefront/sections/RelatedProducts.tsx`

## اختبارات تمت إضافتها

- `frontend/src/storefront/__tests__/CartDrawer.khemet.test.tsx`
  - يثبت أن زر الدفع خارج منطقة الأب سيل القابلة للتمرير.
  - يثبت أن السلة تعيد التمرير للأعلى عند الفتح.

- `frontend/src/storefront/__tests__/RelatedProducts.elessiCompleteSet.test.tsx`
  - يثبت عدم عرض `EGP 0.00` كسعر مقارنة.
  - يثبت استمرار عرض سعر المقارنة الحقيقي عندما يكون أكبر من السعر الحالي.

## بوابات الجودة المحلية

- `npm exec vitest run src/storefront/__tests__/CartDrawer.khemet.test.tsx src/storefront/__tests__/RelatedProducts.elessiCompleteSet.test.tsx --environment jsdom`
- `npm run validate:themes`
- `npm run build`

ملاحظات:

- فحص `audit:storefront-centering:core` يحتاج Dev Server محلي على `localhost:3001`، وفشل فقط لأن السيرفر المحلي لم يكن شغالا.
- فحص `npm run test:storefront-themes` ما زال به فشل قديم خارج نطاق إصلاح Swan الحالي، مثل `storefrontPreview.test.tsx` الذي يتوقع 3 عناصر seeded في Elegant Luxe بينما الحالة الحالية ترجع عنصر واحد. بعد تأمين `scrollTo` لم يعد فشل السلة الجديد يظهر في هذا الاختبار.
