# social-image-generation

## متى تستخدم هذه الـ Skill
- عندما يطلب المستخدم إنشاء صورة للسوشيال ميديا.
- عندما يريد تصميم منشور أو إعلان مصور.
- عندما يحتاج صورة لمنتج أو خدمة.

## الأدوات المتاحة

### generate_social_image
**امتى:** بعد جمع وصف الصورة من المستخدم.
**كيف:** اجمع:
- `prompt`: وصف دقيق للصورة المطلوبة.
- `style`: النمط (realistic, cinematic, minimalist, cartoon, etc.)
- `aspect_ratio`: 1:1, 16:9, 4:5, 9:16 (اختياري)
- `productImage`: رابط صورة مرجعية (اختياري)

## خطوات التنفيذ
1. اسأل عن وصف الصورة المطلوبة.
2. اعرض خيارات النمط ونسبة الأبعاد إذا كان المستخدم مش متأكد.
3. بعد التوليد، اعرض الصورة واسأل إذا كان يريد تعديلات.
4. لو الصورة مش كويسة، اقترح تحسين الـ prompt وجرب تاني.

## ممنوعات
- لا تولد محتوى غير لائق أو مسيء.
- لا تستخدم الصورة بدون موافقة المستخدم.
