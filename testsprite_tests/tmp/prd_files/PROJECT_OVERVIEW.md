# 🚀 منصة التواصل والتجارة الإلكترونية المتكاملة

## 📋 نظرة عامة على المشروع

هذا المشروع عبارة عن **منصة تواصل وتجارة إلكترونية متكاملة** تجمع بين إدارة المحادثات، التجارة الإلكترونية، والذكاء الاصطناعي في نظام واحد شامل. المنصة مصممة لتكون حلاً متكاملاً للشركات التي تريد إدارة عملائها وبيع منتجاتها عبر قنوات متعددة.

---

## 🏗️ الهيكل العام للمشروع

### 📁 **Backend** (Node.js + Express + Prisma)
- **المسار**: `backend/`
- **التقنيات**: Node.js, Express.js, Prisma ORM, MySQL
- **الوظيفة**: خدمات API، قاعدة البيانات، منطق الأعمال. يتميز بهيكلية **Modular Prisma Schema** لتسهيل إدارة الجداول المعقدة.

### 📁 **Frontend** (React + TypeScript + Vite)
- **المسار**: `frontend/`
- **التقنيات**: React 18, TypeScript, Vite, TailwindCSS, Material-UI
- **الوظيفة**: واجهة المستخدم، لوحات التحكم، تجربة المستخدم. تدعم **Internationalization (i18n)** بشكل كامل (عربي/إنجليزي) مع دعم RTL/LTR.

## 3. 🛒 **نظام التجارة الإلكترونية (E-commerce)**

### المميزات:
- **إدارة المنتجات**: إضافة وتعديل المنتجات
- **إدارة الطلبات**: معالجة الطلبات والمدفوعات
- **سير عمل الطلبات (Order Workflow)**: نظام متطور لإدارة حالات الطلبات والقواعد المخصصة للانتقال بينها مع دعم التصاريح والسجلات (Audit Logs).
- **إشعارات واتساب للطلبات (WhatsApp Order Notifications)**: نظام متكامل لإرسال رسائل واتساب عند تغير حالة الطلب. يدعم **75 حالة طلب** مصنفة. تم تحسين النظام ليدعم توزيع الأحمال (Load Balancing) عبر جلسات واتساب المتعددة.
- **استقرار جلسات واتساب (WhatsApp Reliability)**: حل مشاكل الـ 500 error وتعديل جداول قاعدة البيانات (loadBalanceWeight) لضمان استمرارية الخدمة.
- **تدقيق البيانات (Data Integrity)**: نظام آلي لتنظيف الحسابات الوهمية وتصحيح ارتباطات الشركات بالمستخدمين لضمان دقة التقارير.
- **نظام الكوبونات**: خصومات وعروض
- **إدارة المخزون**: تتبع الكميات
- **متجر عام شامل**: واجهة للعملاء تدعم الثيمات المتعددة (Untitled, Luxury, Creative).
- **نظام الصفحات المتعددة (Multi-page Storefront)**: صفحات متكاملة للمتجر تشمل (About, FAQ, Blog, Contact, Track Order, Order Confirmation) مع دعم التبديل التلقائي بين الثيمات بناءً على إعدادات المتجر.
- **نظام إنشاء الطلبات المتقدم**: توافق كامل بين حالات الطلب (Enums) وقواعد البيانات لضمان إنشاء طلبات مرنة (مجدولة وتدعم المحافظ الإلكترونية).
- **تحسينات واجهة المتجر**: دعم الفلاتر المتقدمة، العد التنازلي للعروض، ونظام المقارنة السريع.

## 8. 👥 **نظام إدارة الموارد البشرية (HR)**

- **حسابي (My Account)**: واجهة خاصة للموظفين لمتابعة كشوف مرتباتهم وتحديثات رواتبهم الشخصية بشكل لحظي.
- **تقييم الأداء**: نظام تقييم شامل
- **التقارير**: تحليلات الموارد البشرية
- **إدارة الموظفين**: ملفات شاملة للموظفين

- **إدارة الهيكل الإداري**: تنظيم الأقسام والإدارات
