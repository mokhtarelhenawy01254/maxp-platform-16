# Tasks Workspace Settings

## Overview

صفحة الإعدادات داخل مساحة المهام موجودة على:

- `/tasks/settings`

الصفحة تحفظ تفضيلات المستخدم محليًا لكل شركة/مستخدم، وتم تبسيطها لتعرض إعدادات فعلية فقط بدون شروحات أو بطاقات QA داخل الواجهة.

## What The Settings Page Controls

- `النطاق الافتراضي`
- `الترتيب الافتراضي`
- `اتجاه الترتيب`
- `عدد العناصر في الصفحة`
- `إخفاء المهام المكتملة افتراضيًا`
- `إظهار شريط الأوامر في الجوال`
- `إبراز المهام المتأخرة` للمدير
- `إظهار زر مشروع جديد` للمدير

## Manual Smoke Checks

1. افتح `/tasks/settings`.
   النتيجة المتوقعة: تظهر فقط الحقول والأزرار `حفظ` و`افتراضي` بدون معاينات أو شروحات أو محتوى QA.

2. عدّل `عدد العناصر في الصفحة` أو `النطاق الافتراضي` ثم احفظ وارجع إلى `/tasks`.
   النتيجة المتوقعة: القيم المحفوظة تنعكس على صفحة المهام بعد الرجوع أو إعادة التحميل.

3. افتح `/tasks` بحساب موظف.
   النتيجة المتوقعة: تحديث الحالة من قائمة المهام يظل متاحًا، بينما تبويب `تكاملات المهام` لا يظهر إذا لم تكن الصلاحية تسمح.

4. افتح `مهمة جديدة` وفعّل زر التكرار.
   النتيجة المتوقعة: يتحول الزر من `تفعيل التكرار` إلى `إيقاف التكرار` وتظهر حقول التكرار.
