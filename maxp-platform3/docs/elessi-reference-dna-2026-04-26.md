## Core Elessi DNA

### 1. Rich Commerce Surface

- المتجر ليس landing page minimalist
- الصفحة يجب أن تبدو `ready to shop`
- هناك دائمًا أكثر من مسار دخول:
  - search
  - category
  - promotion
  - collection
  - PDP shortcut

### 2. Merchandising-First Browsing

- `Elessi` قوي في:
  - category banners
  - product strips
  - deal areas
  - seasonal hooks
  - category-specific home demos
- الروح المطلوبة:
  - كثافة مفيدة
  - لا زخرفة فارغة

### 3. Quick-Interaction Commerce

- feature stack الظاهر في المرجع:
  - `AJAX search & suggestions`
  - `off-canvas cart`
  - `off-canvas wishlist`
  - `quick view`
  - `compare`
  - `swatches`
  - `sticky add to cart`
  - `bought together`
  - `shipping bar`
  - `trusted badge`
  - `photo/video review`
  - `360 viewer`

### 4. PDP As Decision Surface

- صفحة المنتج في `Elessi` لا تعرض المنتج فقط
- هي تحاول حسم القرار عبر:
  - media depth
  - variant selectors
  - urgency / quantity signals
  - delivery & return info
  - bundle or related logic
  - buy-now proximity

### 5. Category Adaptability With Shared Spirit

- نفس الـ engine يظهر في `Elessi` عبر demos متعددة:
  - bags
  - bike
  - organic
  - digital
  - cosmetic
  - jewelry
  - pet accessories
  - watches
  - auto parts
  - plant
- هذا مهم لأنه يثبت أن `Elessi` ليس style واحدًا فقط، بل `commerce family`

### 6. Mobile Utility Matters

- المرجع يعرض mobile simulation صريحة
- السلوكيات الجديرة بالاستخراج:
  - shop filter access
  - single-product focus
  - add-to-cart / buy-now proximity
  - review access
  - compare
  - size guide
  - ask a question
  - delivery / return access
  - live search

## What We Keep From Elessi

- كثافة التجارة المفيدة
- منطق `browse fast, decide fast`
- كثرة مسارات الدخول للمنتج
- مزج discovery مع conversion
- category-specific merchandising
- utility layers التي تقلل الاحتكاك
- PDP التي تجمع:
  - product facts
  - trust
  - urgency
  - service

## What We Reject From Elessi

- `slider sprawl`
- multipurpose noise بلا hierarchy واضحة
- fake urgency أو social proof الرخيص
- تكرار البلوكات فقط لملء الصفحة
- chrome مزدحم يخفي المنتج
- استنساخ layouts كما هي
- أي anatomy قديمة ثم تغيير palette فقط

## New Library Targets

- new `hero` families inspired by category merchandising, not generic sliders
- new `shop chrome` families derived from Elessi browse behavior
- new `product-card` families with stronger category anatomy
- new `PDP decision surfaces`
- new `trust / service` surfaces
- new `cart / checkout reassurance` treatments
- shared capabilities extracted once, then styled differently per theme

## Non-Negotiable Pack Rules

- `Elessi` is the single design anchor for this pack
- no second storefront reference may define user-facing anatomy during the first pack wave
- all `critical user-facing families` in shipped themes must be `New to library`
- existing library reuse is allowed only for:
  - engine
  - data plumbing
  - business logic
  - registry / validation / preview infrastructure
- every theme must feel like:
  - same commerce family
  - different category personality
  - different page signatures

## Required Divergence Axes Across The 10 Themes

- hero entry logic
- category navigation style
- product-card anatomy
- shop browsing chrome
- PDP decision chrome
- trust mechanism
- bundle / upsell behavior
- mobile buying rhythm
- visual density
- image framing language

## Hard Reject Conditions

- theme looks like existing library theme with Elessi copy pasted on top
- visible critical surfaces come from old library variants
- theme only changes palette or font
- Elessi is mentioned as inspiration but not traceable in actual capabilities
- multiple themes in the pack collapse into the same anatomy family
