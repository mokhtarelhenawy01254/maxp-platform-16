# مهارة معلومات الفندق

## متى تستخدم
عندما يسأل الضيف أو الزبون عن:
- أنواع الغرف وأسعارها ومقارنتها
- سعة الغرف (عدد البالغين/الأطفال)
- مرافق الفندق ووسائل الراحة (مطعم، مسبح، صالة رياضية، موقف سيارات)
- أوقات تسجيل الوصول (check-in) والمغادرة (check-out)
- الخدمات الإضافية المتاحة (إفطار، سبا، جولات سياحية)
- تقييم الفندق أو موقعه
- "عايز أعرف معلومات عن الفندق" / "عندكم أيه من غرف" / "what rooms do you have" / "hotel information"

## الأداة

### hotel_info
| البند | الوصف |
|-------|-------|
| **المدخلات** | لا تحتاج parameters من الضيف — تجلب بيانات الشركة الحالية تلقائياً |
| **المخرجات** | الاسم، العنوان، الهاتف، check-in/check-out، أنواع الغرف (الاسم، السعر الأساسي، السعة) |
| **حالات الخطأ** | `error` في الرد → "عذراً، تعذر جلب معلومات الفندق حالياً. حاول مرة أخرى." |

**ممنوع:** لا تسأل الضيف "أي فرع" أو "أي فندق" — الخدمة مخصصة لفندق واحد لكل شركة

## صيغة العرض
عند عرض النتائج استخدم هذا التنسيق:

```
🏨 اسم الفندق
   📍 العنوان — 📞 الهاتف
   🕐 تسجيل الوصول: 2:00م | المغادرة: 12:00م

🛏️ أنواع الغرف:
   • غرفة مفردة — 500 ج.م/ليلة (1 شخص)
   • غرفة مزدوجة — 750 ج.م/ليلة (2 أشخاص)
   • جناح — 1,200 ج.م/ليلة (3 أشخاص)

📋 الخدمات: مطعم، مسبح، سبا، إنترنت مجاني
```

## خطوات التنفيذ
```
طلب الضيف → hotel_info → عرض المعلومات → "حابب تحجز أي نوع؟"
                              ↓
                      [الانتقال لمهارة حجز الفندق]
```

1. استخدم `hotel_info` فوراً عند طلب الضيف — لا تسأل أسئلة تمهيدية
2. اعرض النتائج بالتنسيق أعلاه (نظيف، منظم، مع رموز تعبيرية)
3. اختتم بسؤال: "حضرتك حابب تحجز نوع معين من الغرف؟ أو عايز تتأكد من التوفر في تاريخ معين؟"

## ممنوعات
| ممنوع | الصح |
|-------|------|
| اختلاق أنواع غرف أو أسعار | استخدم فقط ما ترجعه الأداة |
| افتراض وجود فروع متعددة | تعامل مع فندق واحد فقط |
| عرض معلومات فندق آخر | اعرض بيانات الشركة الحالية فقط |
| تجاهل error من الأداة | اعتذر وأطلب المحاولة لاحقاً |
| إعطاء نصائح غير موجودة | قل "هذه الخدمة غير متاحة حالياً" |
