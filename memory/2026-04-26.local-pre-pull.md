## PC HUB wide-screen alignment root cause + fix

- investigated the recurring `pc-hub-eg` report that most pages feel pushed to the right with a large empty strip on the left on wider monitors
- reproduced the issue at `2200px` wide and measured the actual layout in the browser instead of relying on section-level guesses
- root cause turned out to be the shared Tailwind `.container` utility inside the storefront `RTL` shell:
  - the container had a max width but no auto-centering
  - in `dir="rtl"` that made the wide layout snap to the right edge instead of centering
- measured before on `shop`:
  - `pageComposer.left = 664`
  - `pageComposer.right = 2200`
  - `pageComposer.width = 1536`
- fixed it in a storefront-scoped way:
  - added `frontend/src/storefront/styles/storefront-layout.css`
  - rule: `.storefront-shell .container { margin-inline: auto; }`
  - added `storefront-shell` to the main storefront root in `frontend/src/storefront/StorefrontShell.tsx`
- measured after on `shop` at the same `2200px` width:
  - `pageComposer.left = 332`
  - `pageComposer.right = 1868`
  - `pageComposer.width = 1536`
- visually rechecked the whole journey after the fix with fresh wide-screen screenshots:
