# Super Admin Companies V2 — Design Improvements

- Added 4 stat cards at top (total, activated, needs follow-up, stale 72h+)
- Stat cards are clickable and auto-set the matching filter
- Made saved views (filter tabs) always visible regardless of collapse state
- Widened column visibility so funnel, last activity, stats, created-at all show at `lg` breakpoint
- Action buttons (follow-up, details, login-as-admin) now always visible, no hover reveal
- Sticky table header with subtle backdrop blur
- Alternating row colors (striping) for readability
- Highlight attention rows (amber) and critical stale rows (rose) with left border
- Mobile card: added funnel stage badge + action buttons in expanded section
- Sort dropdown now shows human-readable labels instead of raw values
