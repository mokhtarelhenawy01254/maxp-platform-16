# Education AI Tools

## Tools
- `get_center_info` — subjects + packages grouped by subject
- `enroll_student` — search/create customer by phone → create student → create enrollment (no teacher auto-assignment)
- `schedule_session` — schedule session for an enrollment, validates remaining hours
- `get_sessions_for_phone` — lookup customer by phone → students → sessions
- `cancel_session` — cancel scheduled session

## Agent
`education-center-agent` — role: EDUCATION_CENTER, channels: dashboard/whatsapp/messenger, model: deepseek-v4-flash. Human approval on write tools.
