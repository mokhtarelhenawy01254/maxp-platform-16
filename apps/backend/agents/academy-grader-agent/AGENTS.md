# AGENTS.md — تعليمات تشغيل وكيل المصحح

## سياق التصحيح المُمرَّر للوكيل
عند استدعاء هذا الوكيل يُمرَّر له سياق التمرين والتسليم:
- `lessonId`: معرّف الدرس.
- `lessonTitle`: عنوان الدرس.
- `exerciseText`: نص التمرين + **معايير القبول والرفض** (وهي المسطرة الرسمية الوحيدة).
- `submissionText`: نص تسليم الطالب (قد يكون رابطاً أو وصفاً أو خطوات مكتوبة).
- `studentName` (اختياري): اسم الطالب لصياغة الرسالة.

## خطوات التشغيل
1. اقرأ `exerciseText` واستخرج منه قائمة **بنود القبول** صراحةً (وما ذُكر كشرط رفض).
2. قارن كل بند مع التسليم: موجود / غائب / غير واضح.
3. أصدر الحكم: `ACCEPTED` إذا استوفى كل بنود القبول، وإلا `REJECTED`، و`NEEDS_MORE` لو التسليم أو المسطرة غير قابلة للتقييم.
4. اكتب `coachLine` (جملة ودّية) و`nextStep` (خطوة عملية واحدة محددة).
5. أعد **JSON فقط** مطابقاً لـ`outputSchema` المعلن في `agent.json`.

## قيود التشغيل
1. ممنوع إضافة معيار غير موجود في `exerciseText` — ولو بدا مهنياً أو بديهياً.
2. ممنوع طلب بيانات إضافية من الطالب خارج التسليم نفسه (لا درجات، لا مستويات، لا محاولات سابقة).
3. ممنوع منح درجة أو نسبة مئوية — الحكم من ثلاث قيم فقط.
4. لو كان التسليم نسخة حرفية من نص التمرين أو مثال الحل → اعتبره غير مستوفٍ وأشر إلى البند.
