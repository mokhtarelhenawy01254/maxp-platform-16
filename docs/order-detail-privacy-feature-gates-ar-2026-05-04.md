# حماية تفاصيل الطلب وتطبيقات التشغيل الاختيارية

التاريخ: 2026-05-04

## الهدف

فصل بيانات التشغيل الداخلي عن شاشة التاجر داخل تفاصيل الطلب، وتحويل بعض بيانات الطلب إلى تطبيقات اختيارية تفعّلها كل شركة عند الحاجة.

## ما تم تنفيذه

- بوابة التاجر لا تعرض بيانات تخص `مصدر الطلب`، `بيانات الحملة`، `بيانات التأكيد والتوزيع`، أو `المسوق والأرباح`.
- `orders-new/simple` و `orders-new/simple/:orderNumber` ينظفان استجابة التاجر من الحقول الداخلية حتى لو حاول الوصول لها مباشرة من API.
- مسؤولو الشركة يرون بيانات المصدر والحملة والتأكيد فقط إذا كانت التطبيقات المناسبة مفعلة، مع استمرار إخفائها عند عدم التفعيل.
- تمت إضافة التطبيقات التالية إلى كتالوج التطبيقات:
  - `order-source-tracking`
  - `campaign-attribution`
  - `order-confirmation-distribution`
- فلتر مصدر الطلب في شاشة الطلبات أصبح يظهر فقط عند تفعيل تطبيق `order-source-tracking` أو وجود فلتر مصدر نشط في الرابط.
- صفحة `/merchant-portal/commissions` لم تعد تعرض الهيدر الكبير الخاص ببوابة التاجر، وتبدأ مباشرة من قسم `مستحقاتي`.

## التحقق المحلي

- `node --check backend/routes/orders.js` نجح.
- `npm run catalog:validate` نجح.
- `npm run catalog:sync-target -- --apps-only` أنشأ التطبيقات الثلاثة محليا.
- ESLint المستهدف نجح للملفات المعدلة بعد تعطيل دين legacy قديم في `no-explicit-any` داخل ملفات تفاصيل الطلب.
- API smoke:
  - قبل تفعيل التطبيقات: الشركة لا ترى source/campaign/confirmation.
  - بعد التفعيل: الشركة ترى هذه الأقسام.
  - التاجر لا يرى الحقول المحظورة ولا قيم أرباح المسوق أو حقول مصدر الطلب.
- Browser smoke:
  - حساب التاجر على `/merchant-portal/commissions` يرى `مستحقاتي` فقط بدون هيدر الترحيب.
  - حساب التاجر على `/orders/ORD-829611-313` لا يرى بيانات المصدر أو الحملة أو التأكيد أو المسوق والأرباح.
  - حساب مالك الشركة بعد تفعيل التطبيقات يرى الأقسام الاختيارية في تفاصيل الطلب.

- تم رفع تحديث backend الخاص بتنظيف بيانات الطلب وإعادة تشغيل `maxp-backend` بنجاح، وصحة backend على port `3007` كانت سليمة.
- تم بناء frontend محليا بنجاح ثم رفع `dist` كاملا إلى الإنتاج على أجزاء صغيرة، مع التحقق من SHA-256 قبل تبديل النسخة.

- تحقق Nginx من خدمة النسخة الجديدة على `https://mokhtarelhenawy.online/merchant-portal/commissions`، والـ index الحالي يشير إلى `assets/index-DDlJ9y54.js`.
