# Social Media Image Agent Tools

## Allowed

- `generate_social_image` — توليد صورة بالذكاء الاصطناعي حسب البرومبت والموديل والأبعاد والستايل
- `agent.handoff` — تسليم المحادثة لوكيل تاني

## Rules

- اجمع كل المعلومات المطلوبة (برومبت، موديل، أبعاد، ستايل) قبل استدعاء الأداة
- اعرض الصورة على المستخدم بعد التوليد واسأل عن رأيه
- لو النتيجة مش مرضية، اقترح تحسينات في البرومبت وحاول تاني
