تاجرالمرحلة 1: التاجر بيبني الصفحة

8 خطوات من أول ما بيدخل اللوحة لحد ما الصفحة تنزل

1

تسجيل دخول

التاجر بيدخل maxp.online بالـ OTP أو الباسورد

2

فتح قسم Landings

من الـ sidebar → التسويق → صفحات الهبوط

أو مباشرة: /advertising/product-landing-pages

3

دوس "إنشاء صفحة جديدة"

يفتح wizard بـ 4 steps

4

اختيار المنتج

بيختار Swan Skotch من dropdown (25 منتج موجودين)

5

اختيار طريقة الإنشاء

4 خيارات:

🚀 Quick Funnel (جديد) — يولّد كل حاجة في 30 ثانية
🤖 Reference Clone — يلصق لينك أي صفحة تنافسية
✍️ AI Copy — يكتب prompt والـ AI يكتب
🛠️ Manual (Phase 2) — drag-and-drop
6

انتظار التوليد (30-90 ثانية)

النظام بيولّد في الخلفية:

⏳ Hero section → Bundle tiers (3) → Countdown → Scarcity → Sold counter → FOMO → Features → Reviews → Trust badges → Order form
7

المعاينة + التعديل البسيط

Desktop / Mobile preview → يعدّل العنوان أو السعر → دوس "نشر"

8

الصفحة تنشر

https://swan.maxp.online/p/socks — دلوقتي العميل يقدر يفتحها

عميلالمرحلة 2: العميل بيشتري

7 خطوات من إعلان فيسبوك لين تأكيد الطلب

1

شاف إعلان على Facebook

"كوتشي swan - خفة وأناقة بخطوة 🔥 خصم 29% — شحن مجاني"

2

دوس على اللينك

المتصفح يفتح https://swan.maxp.online/p/socks

الصفحة تفتح (Mobile-first)

اختار باكدج 3 (الأفضل)

6

دوس "تأكيد الطلب"

نظامالمرحلة 3: Technical Flow

شغل ورا الكواليس — APIs + Database + AI

1

POST /api/v1/product-landings

التاجر يدوس "نشر" → الـ frontend يبعت request للـ backend

POST /api/v1/product-landings
Body: { productId: "abc-123", generationMode: "QUICK_FUNNEL" }
2

Database INSERT

Backend بيعمل record في product_landing_pages table

status: DRAFT
generationStatus: GENERATING
companyId: cmleybpf70028juo2wwpmp8rt
3

AI Generation Pipeline

الـ backend بيشغّل الـ AI عشان يولّد:

→ Hero copy (عربي من AI runtime)
→ 6 image slices (من Image Studio / Gemini)
→ Bundle tier config (3 tiers)
→ formConfig (orderKicker, orderTitle, orderCopy, buttonLabel)
→ Trust badges + Reviews template
4

Update status → READY

الـ slices + formConfig يتسجلوا في الـ DB، الـ status يتغير لـ READY

5

Merchant publishes

دوس "نشر" → status: PUBLISHED + publishedAt: timestamp

6

Customer visits public URL

GET /api/v1/product-landings/public/socks

الـ backend بيرجع الـ landing data + product data + company data

7

Storefront renders

ProductImageLandingPage.tsx بيرسم الصفحة على الموبايل

8

Customer submits order

POST /api/v1/product-landings/public/socks/order

الطلب يتسجل في orders table + إشعار للـ merchant
